Remind me — three concepts

All three use the same server: a System DM, live quotes, and /remind + /reminders. They differ in how you set a reminder, how a fired one looks, and where the pending list lives. Pick one or mix.

A · Menu submenu, quote card, side-panel list

Fits the existing "More actions" menu. Presets live in a submenu; Custom… opens a small date/time dialog. The fired DM is a normal System message with a quote card. /reminders (or a header button in the System DM) opens the list in the right side panel, the same place as pins and threads.

B · Own toolbar button, quick-type popover, inline pending chip

A ⏰ button sits directly on the hover toolbar. It opens a popover that combines preset chips with a text field using the same syntax as /remind ("2h", "14:30", "fri 9"), plus a live preview of the resolved time. While a reminder is pending, the message shows a small amber chip that only you see. The fired DM is a compact one-liner with buttons. Pending reminders show as a pinned strip at the top of the System DM, so no extra panel.

C · "Reminders" as its own destination, with an agenda view and a time-wheel picker

The System DM is pinned at the top of the DM list as "Reminders", with a count of upcoming ones. Opening it shows an agenda: upcoming items grouped by Today / Tomorrow / Later at the top, and delivered reminders below as large cards with Jump and Done. You set a reminder with a dialog built around scroll wheels for day, hour and minute (touch-friendly, the same on phone). /remind adds an inline autocomplete hint while you type.
