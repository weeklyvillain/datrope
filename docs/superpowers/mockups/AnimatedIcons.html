Animated icons: hover motion, 3 concepts

Same app surfaces, three motion personalities. Hover any icon button, or press Replay to run every button in sequence. Static status icons (channel #, speaker, music note) never move, only icons inside buttons do.

Nudge. Tiny, state-like shift that holds while hovered and eases back on leave: gear turns 45°, trash lid lifts 2px, reply leans left, send leans right. 180 ms, ease-out-quint, no overshoot. Quiet and professional, like Linear.

Spring. One-shot, playful motion that tells each icon's story: lid pops off the trash, bell rings, dots wave, pin drops in, play pops, repeat spins. ~600 ms springs with overshoot. Closest to lucide-animated's defaults.

Redraw. One uniform effect for every icon: strokes redraw themselves part by part while the icon tints to primary green. No per-icon choreography, so all 129 icons get identical treatment and the 73 missing ones are trivial to add.
