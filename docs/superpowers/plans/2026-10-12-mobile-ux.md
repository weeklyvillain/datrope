# Mobile UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Datrope web client (installed PWA) feel native on phones across every view: touch-sized, keyboard-aware, edge-to-edge, with a bottom-tab shell, long-press action sheets and no hover/drag/keyboard-only features.

**Architecture:** Three phases. Phase 1 adds small pure modules (gesture/keyboard/history/enter-key logic) plus CSS and primitive changes that every view inherits. Phase 2 adds a phone-only shell (`app/mobile/`) picked by `AppShell` below 768 px, and the chat-level phone interactions. Phase 3 adapts the remaining surfaces. Desktop (`pointer: fine`, ≥768 px) keeps its current behaviour.

**Tech Stack:** React 18, react-router-dom 6 (`createBrowserRouter`), zustand (vanilla stores), shadcn/ui new-york + Radix (`radix-ui`), Tailwind CSS v4, dnd-kit, vitest 2 (node environment, `renderToStaticMarkup` pattern), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-12-mobile-ux-design.md` (audit: `docs/superpowers/specs/2026-10-12-mobile-ux-audit.md`, product: `PRODUCT.md`)

## Global Constraints

- **Never commit.** AGENTS.md: no `git commit`/`push`/`stash`/amend; leave changes in the working tree. Tasks end with a review pause.
- All paths below are relative to `clients/web/` unless they start with `docs/` or `server/`.
- Phone layout = viewport < 768 px (`useIsMobile()`, `MOBILE_QUERY = "(max-width: 767px)"` in `src/hooks/use-mobile.ts`). Touch = `(pointer: coarse)` → Tailwind `pointer-coarse:` variant. Sizing/visibility keys off touch; layout keys off phone width.
- Touch targets ≥ 44×44 px on touch (`min-h-11 min-w-11`); text inputs 16 px on phones (`text-base md:text-sm`).
- Long-press 500 ms, cancelled by > 8 px movement or scroll. Swipe-to-reply threshold 64 px, axis lock at 10 px, max drag 96 px.
- Enter key: touch-only = `matchMedia("(pointer: coarse)").matches && !matchMedia("(any-pointer: fine)").matches`; touch-only → Enter inserts newline; otherwise Enter sends, Shift+Enter newline; Ctrl/Cmd+Enter always sends.
- Tab bar: Server `/`, Messages `/messages`, Mentions `/mentions`, You `/you` (`/you/:section`); 60 px + safe bottom; hidden on pushed screens.
- Desktop routes and UI unchanged; desktop `/mentions` → navigate to `/` and open the inbox popover; desktop `/you` and `/you/:section` → `openSettings(section)` + navigate `/`.
- Mini bars: voice and music above the tab bar (or above the composer); on pushed screens with both active they collapse into one 56 px row.
- UI rules (AGENTS.md): fetch shadcn components via `pnpm dlx shadcn@latest add <name>` from `clients/web` before building (fallback: fetch JSON from `https://ui.shadcn.com/r/styles/new-york-v4/<name>.json`); tokens only, no hardcoded colors; dark-only (strip `dark:`); `cn()` from `@/lib/utils`; `@/` imports; `React.forwardRef` for `asChild` triggers; keep `Button` defaults (`type="button"`, destructive uses `text-destructive-foreground`), `Slider` aria-label on thumb, `TooltipContent hideWhenDetached`.
- Keep accessible names stable: `Message`, `Desktop notifications`, `Notify me about`, `Messages` (log), `Add reaction`, `Emoji`, `Attach files`, `Code block`, `Send`, `Cancel reply`, `Music player`, etc. New controls get explicit labels: `Back`, `Open channel info`, `More actions`, `Hold to talk`, tab names `Server`, `Messages`, `Mentions`, `You`.
- Reduced motion: every new transition is wrapped in `motion-safe:`; swipe follows the finger without spring-back under `prefers-reduced-motion`.
- Vitest runs in the node environment without testing-library. Put logic in pure functions and test those; component behaviour is verified by Playwright (Task 21).
- Prefix shell commands with `rtk` where available (fallback plain `pnpm`/`npx`).
- Plan narrowing of the spec (deliberate): the phone attach menu holds Upload file and Code block only. The spec also lists GIF and Poll; add them to the menu only if the Composer already has an entry point for them (check `chat/commands.tsx` and `GifDialog.tsx`); otherwise leave them reachable as today and note it in the task report.

## Review Focus

1. **A tap that drifts slightly on a message** (finger moves 3–6 px) must still count as a tap/long-press, not a swipe or scroll; a vertical scroll that starts on a message must never trigger reply. → "tolerates a small drift", "a vertical start never becomes a swipe" and "small drift is undecided" tests in Task 10.
2. **Back button after reload with a panel open** (`?panel=thread:…`): back must leave the panel route sensibly, not loop. → `panel-param` test "reload state" in Task 6.
3. **Hardware keyboard on a phone/tablet** (`any-pointer: fine`) keeps Enter-to-send. → `enterAction` cases in Task 5.
4. **Rotating across 768 px mid-conversation** swaps shells and keeps the route. → Playwright step in Task 21 (`setViewportSize` 900→390).
5. **A message with no content (image-only) or a system message** long-pressed: sheet omits Copy; system/deleted/pending messages open nothing. → `messageActions` pure test in Task 11.

```ts
// src/lib/keyboard-inset.ts
/** How much of the layout viewport the on-screen keyboard covers, in px. */
export function keyboardInset(innerHeight: number, vv: { height: number; offsetTop: number } | null): number {
  if (!vv) return 0;
  return Math.max(0, Math.round(innerHeight - vv.height - vv.offsetTop));
}
```

```ts
// src/hooks/use-visual-viewport.ts
import { useEffect } from "react";
import { keyboardInset } from "@/lib/keyboard-inset";

/** Keeps --keyboard-inset in step with the on-screen keyboard (iOS overlays it; Android resizes). */
export function useVisualViewport() {
  useEffect(() => {
    const vv = window.visualViewport;
    if (!vv) return;
    const root = document.documentElement;
    const update = () => root.style.setProperty("--keyboard-inset", `${keyboardInset(window.innerHeight, vv)}px`);
    update();
    vv.addEventListener("resize", update);
    vv.addEventListener("scroll", update);
    return () => {
      vv.removeEventListener("resize", update);
      vv.removeEventListener("scroll", update);
      root.style.removeProperty("--keyboard-inset");
    };
  }, []);
}
```

```ts
// src/lib/history-layers.ts
export type HistoryLike = {
  push(state: unknown, url?: string): void;
  replace(state: unknown, url?: string): void;
  back(): void;
  current(): unknown;
};
export type Layers = {
  open(id: string, onClose: () => void, url?: string): void;
  close(id: string): void;
  popped(state: unknown): void;
  depth(): number;
};

const KEY = "datropeLayer";
type Entry = { id: string; onClose: () => void };
const depthOf = (state: unknown) =>
  state && typeof state === "object" && KEY in state ? (state as Record<string, { depth: number }>)[KEY].depth : 0;

/** Phone layers (panels, sheets, full-screen screens) as history entries, so Back closes the top one. */
export function createLayers(h: HistoryLike): Layers {
  const stack: Entry[] = [];
  let closing: string | null = null;
  const finish = (until: number) => {
    while (stack.length > until) stack.pop()!.onClose();
  };
  return {
    open(id, onClose, url) {
      const at = stack.findIndex((e) => e.id === id);
      if (at >= 0) { stack[at].onClose = onClose; return; }
      stack.push({ id, onClose });
      const prev = h.current();
      h.push({ ...(prev && typeof prev === "object" ? prev : {}), [KEY]: { id, depth: stack.length } }, url);
    },
    close(id) {
      const at = stack.findIndex((e) => e.id === id);
      if (at < 0) return;
      if (at === stack.length - 1 && depthOf(h.current()) === stack.length) {
        closing = id;
        h.back();
        return;
      }
      stack.splice(at, 1)[0].onClose();
    },
    popped(state) {
      closing = null;
      finish(Math.min(stack.length, depthOf(state)));
    },
    depth: () => stack.length,
  };
}
```

(`closing` documents intent; `popped` performs the close so `onClose` runs exactly once.)

```ts
export const layers = createLayers({
  push: (s, url) => window.history.pushState(s, "", url),
  replace: (s, url) => window.history.replaceState(s, "", url),
  back: () => window.history.back(),
  current: () => window.history.state,
});

/** While `open`, the layer owns a history entry: Back calls onClose; closing in the UI pops the entry. */
export function useHistoryLayer(id: string, open: boolean, onClose: () => void) {
  const cb = useRef(onClose);
  cb.current = onClose;
  useEffect(() => {
    if (!open) return;
    layers.open(id, () => cb.current());
    return () => layers.close(id);
  }, [id, open]);
}
```

```ts
// src/lib/long-press.ts
export function createLongPress(o: {
  delay?: number; tolerance?: number; onLongPress: () => void;
  schedule?: (fn: () => void, ms: number) => unknown; cancel?: (t: unknown) => void;
}) {
  const delay = o.delay ?? 500, tol = o.tolerance ?? 8;
  const schedule = o.schedule ?? ((fn, ms) => setTimeout(fn, ms));
  const clear = o.cancel ?? ((t) => clearTimeout(t as ReturnType<typeof setTimeout>));
  let timer: unknown = null, x = 0, y = 0, fired = false;
  const stop = () => { if (timer !== null) clear(timer); timer = null; };
  return {
    down(px: number, py: number) {
      stop(); x = px; y = py; fired = false;
      timer = schedule(() => { timer = null; fired = true; o.onLongPress(); }, delay);
    },
    move(px: number, py: number) { if (Math.hypot(px - x, py - y) > tol) stop(); },
    up() { stop(); const f = fired; fired = false; return f; },
    cancel() { stop(); fired = false; },
  };
}
```

```ts
// src/lib/swipe.ts
export function createSwipe(o: { threshold?: number; lock?: number; max?: number } = {}) {
  const threshold = o.threshold ?? 64, lock = o.lock ?? 10, max = o.max ?? 96;
  let x0 = 0, y0 = 0, axis: "x" | "y" | null = null, dx = 0;
  return {
    down(x: number, y: number) { x0 = x; y0 = y; axis = null; dx = 0; },
    move(x: number, y: number) {
      const ddx = x - x0, ddy = y - y0;
      if (!axis && Math.max(Math.abs(ddx), Math.abs(ddy)) >= lock) axis = Math.abs(ddx) > Math.abs(ddy) ? "x" : "y";
      dx = axis === "x" ? Math.min(max, Math.max(0, ddx)) : 0;
      return { dx, axis };
    },
    up() { const hit = axis === "x" && dx >= threshold; axis = null; dx = 0; return hit; },
  };
}
```

```ts
    onPointerMove: (e: PointerEvent) => { if (touch(e)) lp.move(e.clientX, e.clientY); },

    onContextMenu: (e: MouseEvent) => { if (enabled && (e.nativeEvent as globalThis.PointerEvent).pointerType !== "mouse" && window.matchMedia("(pointer: coarse)").matches) e.preventDefault(); },
```

```ts
/** Swipe a message to the right to reply (touch only). */
export function useSwipeReply(onReply: () => void, enabled: boolean) {
  const [offset, setOffset] = useState(0);
  const cb = useRef(onReply);
  cb.current = onReply;
  const s = useMemo(() => createSwipe(), []);
  const on = (e: PointerEvent) => enabled && e.pointerType === "touch";
  return {
    offset,
    handlers: {
      onPointerDown: (e: PointerEvent) => { if (on(e)) s.down(e.clientX, e.clientY); },
      onPointerMove: (e: PointerEvent) => { if (on(e)) setOffset(s.move(e.clientX, e.clientY).dx); },
      onPointerUp: (e: PointerEvent) => { if (!on(e)) return; if (s.up()) { navigator.vibrate?.(10); cb.current(); } setOffset(0); },
      onPointerCancel: () => { s.up(); setOffset(0); },
    },
  };
```

```ts
// src/chat/recent-emoji.ts
const KEY = "datrope.recentEmoji";
export const DEFAULT_QUICK = ["👍", "❤️", "😂", "🔥", "🎉", "👀"];

export function mergeRecent(list: string[], key: string, max = 12): string[] {
  return [key, ...list.filter((k) => k !== key)].slice(0, max);
}
function load(): string[] {
  try { const v = JSON.parse(localStorage.getItem(KEY) ?? "[]"); return Array.isArray(v) ? v.filter((x) => typeof x === "string") : []; }
  catch { return []; }
}
/** Remembers an emoji someone reacted with or inserted. */
export function recordEmoji(key: string) {
  try { localStorage.setItem(KEY, JSON.stringify(mergeRecent(load(), key))); } catch { /* storage unavailable */ }
}
/** The quick-reaction row: recent picks first, topped up with defaults. */
export function quickReactions(n = 6): string[] {
  const out = load().filter((k) => !k.startsWith("custom:")).slice(0, n);
  for (const d of DEFAULT_QUICK) if (out.length < n && !out.includes(d)) out.push(d);
  return out;
}
```

```ts
// src/app/message-actions.ts
export type MessageAction = "react" | "reply" | "thread" | "edit" | "copy" | "pin" | "album" | "delete";

/** What the phone action sheet offers for a message, in order; null when it offers nothing. */
export function messageActions(
  m: { pending?: boolean; deleted?: boolean; kind?: string; content: string; attachments?: unknown[] | null },
  can: { reply: boolean; react: boolean; thread: boolean; hasThread: boolean; edit: boolean; pin: boolean; pinned: boolean; album: boolean; delete: boolean },
): MessageAction[] | null {
  if (m.pending || m.deleted || m.kind) return null;
  const out: MessageAction[] = [];
  if (can.react) out.push("react");
  if (can.reply) out.push("reply");
  if (can.thread || can.hasThread) out.push("thread");
  if (can.edit) out.push("edit");
  if (m.content) out.push("copy");
  if (can.pin) out.push("pin");
  if (can.album && (m.attachments?.length ?? 0) > 0) out.push("album");
  if (can.delete) out.push("delete");
  return out;
}
```

```ts
// src/lib/viewer-gestures.ts
export function pinchZoom(startZoom: number, startDist: number, dist: number, min = 1, max = 8): number {
  if (startDist <= 0) return startZoom;
  return Math.min(max, Math.max(min, startZoom * (dist / startDist)));
}
export function swipeIntent(dx: number, dy: number): "prev" | "next" | "close" | null {
  if (Math.abs(dx) > 60 && Math.abs(dx) > Math.abs(dy)) return dx < 0 ? "next" : "prev";
  if (dy > 100 && dy > Math.abs(dx)) return "close";
  return null;
}
```
