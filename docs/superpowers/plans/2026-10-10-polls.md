# Polls (piece 3, `/poll`): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/poll [question]` opens a dialog that creates a poll (single or multiple answers, open or anonymous, optional end time). The poll renders inside its message with live counts, and votes, early ends and voter lists work end to end.

**Architecture:**
- **Server.** Migration `00023_polls.sql` adds `polls`, `poll_options` and `poll_votes`. In the `messages` package:
  - `polls.go` validates and stores a poll when a message is created, and `hydrate` attaches it as `Message.Poll`, like reactions.
  - `poll_handlers.go` holds the vote, end and voters endpoints and the `POLL_UPDATE` gateway event (counts only).
  - A poll's end is computed lazily in SQL (`ended_at IS NOT NULL OR ends_at <= now()`). No background job.
  - `my_votes` depends on who asks, so `hydrate` always leaves it empty. Only `GET /messages` and the vote response fill it. This keeps one user's votes out of broadcast events (pins and link previews republish a hydrated message as `MESSAGE_UPDATE`).
- **Core client.** Types are regenerated. The store applies `POLL_UPDATE` and keeps a message's existing poll (with my votes) on `MESSAGE_UPDATE`. `DatropeClient` gets `sendPoll`, `votePoll`, `endPoll` and `pollVoters`.
- **Web.**
  - Pure helpers live in `src/chat/poll.ts`.
  - `PollCard` renders inside `MessageRow`.
  - `PollDialog` is the create modal.
  - The `/poll` command returns `{ open: "poll", query }`, and the Composer opens `PollDialog` through the modal hook-up piece 2 built.

**Tech Stack:** Go 1.25, huma v2, pgx v5, goose, Postgres (testcontainers), TypeScript, zustand, React 18, shadcn/ui (Radix), Tailwind v4, Vitest, msw, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-10-commands-gifs-polls-webhooks-design.md` §3 (`/poll`). The framework it plugs into is §1 (piece 1, done) plus piece 2's additions (see below).

- Spec values copied verbatim:
  - Question 1–300 chars. 2–10 options of 1–55 chars.
  - `duration` ∈ `1h 4h 8h 24h 3d 1w`, or omitted (no end). The dialog defaults to 24h.
  - Error codes `409 POLL_NOT_EDITABLE` and `409 POLL_ENDED`.
  - The voters endpoint returns 404 for anonymous polls.

- Decisions taken here:
  - Limits count characters (runes), after trimming whitespace.
  - Validation failures use the existing `400 VALIDATION_FAILED` code. Bad emoji use `400 INVALID_EMOJI`. Bad vote positions use `400 INVALID_VOTE`.

  - Vote, end and voters need only `ViewChannel` (`access(ctx, id, 0)`), as the spec says.
  - Votes are rate limited per user (60/min, burst 10), like reactions.
  - Messages are **soft-deleted** (`UPDATE messages SET deleted = TRUE`), so the `ON DELETE CASCADE` never fires on delete. The delete handler removes the poll explicitly, as it already does for reactions.

## Review Focus

1. **Anonymous polls leaking voter identity through a side channel.** No voter ID may appear in the message list, the vote response, `POLL_UPDATE` or the voters endpoint. Also: a `MESSAGE_UPDATE` caused by a pin, sent by someone who voted, must not broadcast that person's `my_votes`. Pinned in Task 2 (`TestAnonymousPollHidesVoters`).
2. **Deleting a poll message.** Deletes are soft, so the FK cascade never runs. The poll, options and votes must be gone, the deleted message must have no `poll`, and voting on it must 404. Pinned in Task 1 (`TestPollCannotBeEditedAndGoesWithItsMessage`) and Task 2 (vote on a deleted message).
3. **A timed poll whose end passes with nobody watching.** Voting after `ends_at` must answer `409 POLL_ENDED` and reads must say `ended: true`, with no job running. The open client must flip to "Final results" when the countdown reaches zero. Pinned in Task 2 (`TestPollEnding`, `ends_at` moved into the past) and Task 4 (`isEnded` / `pollFooter` tests, `useNow` timer).
4. **Whitespace and multibyte text.**
   - A question or answer of only spaces must be refused.
   - 300 `é` must be accepted (characters, not bytes).
   - The dialog must drop blank answer rows rather than send them.

   Pinned in Task 1 (`TestPollValidation`) and Task 4 (`buildPoll` tests).
5. **My own votes surviving other events in the client.** A `MESSAGE_UPDATE` for the poll message (pin or link preview), whose `my_votes` is always `[]`, must not clear my checkmarks, and `POLL_UPDATE` must change only counts. Pinned in Task 3 (store test).

```go
// samplePoll is a valid single-answer poll; extra overrides its fields.
func samplePoll(extra map[string]any) map[string]any {
	p := map[string]any{
		"question": "Pizza or tacos?",
		"options":  []map[string]any{{"text": "Pizza", "emoji": "🍕"}, {"text": "Tacos"}},
	}
	for k, v := range extra {
		p[k] = v
	}
	return p
}

func pollOptions(texts ...string) []map[string]any {
	out := make([]map[string]any, len(texts))
	for i, s := range texts {
		out[i] = map[string]any{"text": s}
	}
	return out
}

func numberedOptions(n int) []map[string]any {
	texts := make([]string, n)
	for i := range texts {
		texts[i] = strconv.Itoa(i + 1)
	}
	return pollOptions(texts...)
}
```

```sql
-- +goose Up
-- A message's poll. Messages are soft-deleted, so the messages handler
-- deletes the poll itself; the cascades cover hard deletes (channel deletion).
CREATE TABLE polls (
    message_id BIGINT PRIMARY KEY REFERENCES messages (id) ON DELETE CASCADE,
    question   TEXT NOT NULL,
    multi      BOOLEAN NOT NULL DEFAULT FALSE,
    anonymous  BOOLEAN NOT NULL DEFAULT FALSE,
    ends_at    TIMESTAMPTZ,
    ended_at   TIMESTAMPTZ
);
CREATE TABLE poll_options (
    message_id BIGINT NOT NULL REFERENCES polls (message_id) ON DELETE CASCADE,
    position   SMALLINT NOT NULL,
    text       TEXT NOT NULL,
    emoji      TEXT,
    PRIMARY KEY (message_id, position)
);
CREATE TABLE poll_votes (
    message_id BIGINT NOT NULL,
    position   SMALLINT NOT NULL,
    user_id    BIGINT NOT NULL REFERENCES users (id) ON DELETE CASCADE,
    PRIMARY KEY (message_id, position, user_id),
    FOREIGN KEY (message_id, position) REFERENCES poll_options (message_id, position) ON DELETE CASCADE
);

-- +goose Down
DROP TABLE poll_votes;
DROP TABLE poll_options;
DROP TABLE polls;
```

```go
package messages

import (
	"context"
	"net/http"
	"strings"
	"time"
	"unicode/utf8"

	"github.com/jackc/pgx/v5"

	"github.com/datrope/datrope/server/internal/httpx"
	"github.com/datrope/datrope/server/internal/id"
)

// Poll limits (spec §3), in characters after trimming.
const (
	maxPollQuestion = 300
	maxPollOption   = 55
	minPollOptions  = 2
	maxPollOptions  = 10
)

// pollDurations are the end times a poll may be created with.
var pollDurations = map[string]time.Duration{
	"1h": time.Hour, "4h": 4 * time.Hour, "8h": 8 * time.Hour, "24h": 24 * time.Hour,
	"3d": 72 * time.Hour, "1w": 168 * time.Hour,
}

// pollEndedSQL is true once a poll has ended, early or by its end time (p is polls).
const pollEndedSQL = `(p.ended_at IS NOT NULL OR coalesce(p.ends_at <= now(), FALSE))`

type PollRequest struct {
	Question  string              `json:"question" minLength:"1" maxLength:"300"`
	Options   []PollOptionRequest `json:"options" minItems:"2" maxItems:"10"`
	Multi     bool                `json:"multi,omitempty" doc:"Voters may choose several answers"`
	Anonymous bool                `json:"anonymous,omitempty" doc:"Nobody can see who chose what"`
	Duration  string              `json:"duration,omitempty" enum:"1h,4h,8h,24h,3d,1w" doc:"Omit for a poll that runs until ended"`
}

type PollOptionRequest struct {
	Text  string `json:"text" minLength:"1" maxLength:"55"`
	Emoji string `json:"emoji,omitempty" maxLength:"64" doc:"A Unicode emoji or custom:<emoji id>"`
}

// Poll is a message's poll: counts for everyone, plus the asking user's own votes.
type Poll struct {
	Question    string       `json:"question"`
	Multi       bool         `json:"multi"`
	Anonymous   bool         `json:"anonymous"`
	EndsAt      *time.Time   `json:"ends_at,omitempty" doc:"When the poll closes by itself; absent when it runs until ended"`
	Ended       bool         `json:"ended" doc:"Ended early, or ends_at has passed"`
	Options     []PollOption `json:"options"`
	TotalVoters int          `json:"total_voters"`
	MyVotes     []int        `json:"my_votes" doc:"Positions the requesting user chose; always empty in gateway events"`
}

type PollOption struct {
	Text  string `json:"text"`
	Emoji string `json:"emoji,omitempty" doc:"A Unicode emoji or custom:<emoji id>"`
	Count int    `json:"count"`
}

func errPollNotEditable() *httpx.Error {
	return httpx.E(http.StatusConflict, "POLL_NOT_EDITABLE", "polls cannot be edited")
}

// checkPoll trims a poll request in place and validates it.
func (s *Service) checkPoll(ctx context.Context, p *PollRequest) error {
	invalid := func(msg string) error { return httpx.BadRequest("VALIDATION_FAILED", msg) }
	p.Question = strings.TrimSpace(p.Question)
	if n := utf8.RuneCountInString(p.Question); n < 1 || n > maxPollQuestion {
		return invalid("a poll question needs 1 to 300 characters")
	}
	if len(p.Options) < minPollOptions || len(p.Options) > maxPollOptions {
		return invalid("a poll needs 2 to 10 answers")
	}
	for i := range p.Options {
		o := &p.Options[i]
		o.Text = strings.TrimSpace(o.Text)
		if n := utf8.RuneCountInString(o.Text); n < 1 || n > maxPollOption {
			return invalid("each answer needs 1 to 55 characters")
		}
		if o.Emoji != "" {
			if err := s.checkEmoji(ctx, o.Emoji); err != nil {
				return err
			}
		}
	}
	if _, ok := pollDurations[p.Duration]; p.Duration != "" && !ok {
		return invalid("duration must be one of 1h, 4h, 8h, 24h, 3d and 1w")
	}
	return nil
}

// insertPoll stores the poll of a message being created.
func insertPoll(ctx context.Context, tx pgx.Tx, messageID id.ID, created time.Time, p *PollRequest) error {
	var endsAt *time.Time
	if d, ok := pollDurations[p.Duration]; ok {
		t := created.Add(d)
		endsAt = &t
	}
	if _, err := tx.Exec(ctx, `INSERT INTO polls (message_id, question, multi, anonymous, ends_at) VALUES ($1, $2, $3, $4, $5)`,
		messageID, p.Question, p.Multi, p.Anonymous, endsAt); err != nil {
		return err
	}
	for i, o := range p.Options {
		var emoji *string
		if o.Emoji != "" {
			emoji = &o.Emoji
		}
		if _, err := tx.Exec(ctx, `INSERT INTO poll_options (message_id, position, text, emoji) VALUES ($1, $2, $3, $4)`,
			messageID, i, o.Text, emoji); err != nil {
			return err
		}
	}
	return nil
}

// querier is a pool or a transaction.
type querier interface {
	Query(ctx context.Context, sql string, args ...any) (pgx.Rows, error)
}

// loadPolls reads polls with their vote counts. MyVotes stays empty: it
// depends on who asks (withMyVotes), and events go to everyone.
func loadPolls(ctx context.Context, q querier, messageIDs []id.ID) (map[id.ID]*Poll, error) {
	out := map[id.ID]*Poll{}
	if len(messageIDs) == 0 {
		return out, nil
	}
	rows, err := q.Query(ctx, `
		SELECT p.message_id, p.question, p.multi, p.anonymous, p.ends_at, `+pollEndedSQL+`,
		       (SELECT count(DISTINCT v.user_id) FROM poll_votes v WHERE v.message_id = p.message_id)
		FROM polls p WHERE p.message_id = ANY($1)`, id.Int64s(messageIDs))
	if err != nil {
		return nil, err
	}
	for rows.Next() {
		var mid id.ID
		p := &Poll{Options: []PollOption{}, MyVotes: []int{}}
		if err := rows.Scan(&mid, &p.Question, &p.Multi, &p.Anonymous, &p.EndsAt, &p.Ended, &p.TotalVoters); err != nil {
			rows.Close()
			return nil, err
		}
		out[mid] = p
	}
	rows.Close() // before the next query: a transaction runs one at a time
	if err := rows.Err(); err != nil {
		return nil, err
	}
	if len(out) == 0 {
		return out, nil
	}
	rows, err = q.Query(ctx, `
		SELECT o.message_id, o.text, coalesce(o.emoji, ''), count(v.user_id)
		FROM poll_options o
		LEFT JOIN poll_votes v ON v.message_id = o.message_id AND v.position = o.position
		WHERE o.message_id = ANY($1)
		GROUP BY o.message_id, o.position ORDER BY o.message_id, o.position`, id.Int64s(messageIDs))
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	for rows.Next() {
		var mid id.ID
		var o PollOption
		if err := rows.Scan(&mid, &o.Text, &o.Emoji, &o.Count); err != nil {
			return nil, err
		}
		if p := out[mid]; p != nil {
			p.Options = append(p.Options, o)
		}
	}
	return out, rows.Err()
}

// withPolls fills Poll for poll messages.
func (s *Service) withPolls(ctx context.Context, ms []Message) error {
	ids := make([]id.ID, 0, len(ms))
	for _, m := range ms {
		if !m.Deleted {
			ids = append(ids, m.ID)
		}
	}
	polls, err := loadPolls(ctx, s.db, ids)
	if err != nil {
		return err
	}
	for i := range ms {
		ms[i].Poll = polls[ms[i].ID]
	}
	return nil
}
```

```go
import (
```

```go
type VoteRequest struct {
	Positions []int `json:"positions" maxItems:"10" doc:"The chosen answers by position; empty removes the vote"`
}

// PollUpdate is the POLL_UPDATE event: counts only, never voters.
type PollUpdate struct {
	ChannelID   id.ID             `json:"channel_id"`
	MessageID   id.ID             `json:"message_id"`
	Options     []PollOptionCount `json:"options"`
	TotalVoters int               `json:"total_voters"`
	Ended       bool              `json:"ended"`
}

type PollOptionCount struct {
	Count int `json:"count"`
}

func errPollEnded() *httpx.Error {
	return httpx.E(http.StatusConflict, "POLL_ENDED", "this poll has ended")
}

func errInvalidVote(msg string) *httpx.Error { return httpx.BadRequest("INVALID_VOTE", msg) }

func pollUpdate(channelID, messageID id.ID, p *Poll) PollUpdate {
	u := PollUpdate{ChannelID: channelID, MessageID: messageID, Options: make([]PollOptionCount, len(p.Options)),
		TotalVoters: p.TotalVoters, Ended: p.Ended}
	for i, o := range p.Options {
		u.Options[i] = PollOptionCount{Count: o.Count}
	}
	return u
}

// checkVote validates positions for a poll with n answers and returns them sorted.
func checkVote(positions []int, multi bool, n int) ([]int, error) {
	if !multi && len(positions) > 1 {
		return nil, errInvalidVote("this poll takes one answer")
	}
	out := slices.Clone(positions)
	slices.Sort(out)
	for i, p := range out {
		if p < 0 || p >= n {
			return nil, errInvalidVote("there is no such answer")
		}
		if i > 0 && out[i-1] == p {
			return nil, errInvalidVote("each answer can be chosen once")
		}
	}
	if out == nil {
		out = []int{}
	}
	return out, nil
}

// withMyVotes fills my_votes for userID. Only REST responses carry it:
// hydrated messages are also broadcast (MESSAGE_UPDATE), and those go to everyone.
func (s *Service) withMyVotes(ctx context.Context, ms []Message, userID id.ID) error {
	var ids []id.ID
	for _, m := range ms {
		if m.Poll != nil {
			ids = append(ids, m.ID)
		}
	}
	if len(ids) == 0 {
		return nil
	}
	rows, err := s.db.Query(ctx, `SELECT message_id, position FROM poll_votes WHERE message_id = ANY($1) AND user_id = $2 ORDER BY position`,
		id.Int64s(ids), userID)
	if err != nil {
		return err
	}
	defer rows.Close()
	mine := map[id.ID][]int{}
	for rows.Next() {
		var mid id.ID
		var pos int
		if err := rows.Scan(&mid, &pos); err != nil {
			return err
		}
		mine[mid] = append(mine[mid], pos)
	}
	if err := rows.Err(); err != nil {
		return err
	}
	for i := range ms {
		if v := mine[ms[i].ID]; v != nil && ms[i].Poll != nil {
			ms[i].Poll.MyVotes = v
		}
	}
	return nil
}

func registerPolls(api huma.API, s *Service, op func(string, string, string, int) huma.Operation, access accessFunc) {
	huma.Register(api, op("vote-poll", http.MethodPut, "/api/channels/{id}/messages/{messageID}/poll/vote", 0),
		func(ctx context.Context, in *struct {
			ID        string `path:"id"`
			MessageID string `path:"messageID"`
			Body      VoteRequest
		}) (*struct{ Body *Poll }, error) {
			ch, _, err := access(ctx, in.ID, 0)
			if err != nil {
				return nil, err
			}
			m, err := s.get(ctx, ch.ID, in.MessageID)
			if err != nil {
				return nil, err
			}
			me := auth.Current(ctx).User.ID
			tx, err := s.db.Begin(ctx)
			if err != nil {
				return nil, err
			}
			defer tx.Rollback(ctx)
			// The row lock orders concurrent votes, so each event's counts are current.
			var multi, ended bool
			err = tx.QueryRow(ctx, `SELECT p.multi, `+pollEndedSQL+` FROM polls p WHERE p.message_id = $1 FOR UPDATE`, m.ID).Scan(&multi, &ended)
			if errors.Is(err, pgx.ErrNoRows) {
				return nil, httpx.NotFound("poll")
			}
			if err != nil {
				return nil, err
			}
			if ended {
				return nil, errPollEnded()
			}
			var options int
			if err := tx.QueryRow(ctx, `SELECT count(*) FROM poll_options WHERE message_id = $1`, m.ID).Scan(&options); err != nil {
				return nil, err
			}
			positions, err := checkVote(in.Body.Positions, multi, options)
			if err != nil {
				return nil, err
			}
			if !s.voteLimit.Allow(me.String()) {
				return nil, httpx.RateLimited()
			}
			if _, err := tx.Exec(ctx, `DELETE FROM poll_votes WHERE message_id = $1 AND user_id = $2`, m.ID, me); err != nil {
				return nil, err
			}
			if _, err := tx.Exec(ctx, `INSERT INTO poll_votes (message_id, position, user_id) SELECT $1, unnest($2::int[]), $3`,
				m.ID, positions, me); err != nil {
				return nil, err
			}
			polls, err := loadPolls(ctx, tx, []id.ID{m.ID})
			if err != nil {
				return nil, err
			}
			if err := tx.Commit(ctx); err != nil {
				return nil, err
			}
			p := polls[m.ID]
			s.publish("POLL_UPDATE", ch.ID, pollUpdate(ch.ID, m.ID, p))
			p.MyVotes = positions // after publishing: the event has counts only
			return &struct{ Body *Poll }{p}, nil
		})

	huma.Register(api, op("end-poll", http.MethodPost, "/api/channels/{id}/messages/{messageID}/poll/end", http.StatusNoContent),
		func(ctx context.Context, in *messagePath) (*struct{}, error) {
			ch, have, err := access(ctx, in.ID, 0)
			if err != nil {
				return nil, err
			}
			m, err := s.get(ctx, ch.ID, in.MessageID)
			if err != nil {
				return nil, err
			}
			if m.Author.ID != auth.Current(ctx).User.ID && !have.Has(perms.ManageMessages) {
				return nil, httpx.MissingPermission()
			}
			tx, err := s.db.Begin(ctx)
			if err != nil {
				return nil, err
			}
			defer tx.Rollback(ctx)
			var ended bool
			err = tx.QueryRow(ctx, `SELECT `+pollEndedSQL+` FROM polls p WHERE p.message_id = $1 FOR UPDATE`, m.ID).Scan(&ended)
			if errors.Is(err, pgx.ErrNoRows) {
				return nil, httpx.NotFound("poll")
			}
			if err != nil {
				return nil, err
			}
			if ended {
				return nil, errPollEnded()
			}
			if _, err := tx.Exec(ctx, `UPDATE polls SET ended_at = now() WHERE message_id = $1`, m.ID); err != nil {
				return nil, err
			}
			polls, err := loadPolls(ctx, tx, []id.ID{m.ID})
			if err != nil {
				return nil, err
			}
			if err := tx.Commit(ctx); err != nil {
				return nil, err
			}
			s.publish("POLL_UPDATE", ch.ID, pollUpdate(ch.ID, m.ID, polls[m.ID]))
			return nil, nil
		})

	huma.Register(api, op("list-poll-voters", http.MethodGet, "/api/channels/{id}/messages/{messageID}/poll/options/{n}/voters", 0),
		func(ctx context.Context, in *struct {
			ID        string `path:"id"`
			MessageID string `path:"messageID"`
			N         int    `path:"n" minimum:"0" maximum:"9" doc:"The answer's position"`
		}) (*struct{ Body []auth.PublicUser }, error) {
			ch, _, err := access(ctx, in.ID, 0)
			if err != nil {
				return nil, err
			}
			m, err := s.get(ctx, ch.ID, in.MessageID)
			if err != nil {
				return nil, err
			}
			var anonymous bool
			err = s.db.QueryRow(ctx, `
				SELECT p.anonymous FROM polls p JOIN poll_options o ON o.message_id = p.message_id
				WHERE p.message_id = $1 AND o.position = $2::int`, m.ID, in.N).Scan(&anonymous)
			// Anonymous polls have no voter lists at all.
			if errors.Is(err, pgx.ErrNoRows) || (err == nil && anonymous) {
				return nil, httpx.NotFound("poll answer")
			}
			if err != nil {
				return nil, err
			}
			rows, err := s.db.Query(ctx, `SELECT user_id FROM poll_votes WHERE message_id = $1 AND position = $2::int ORDER BY user_id`, m.ID, in.N)
			if err != nil {
				return nil, err
			}
			ids, err := pgx.CollectRows(rows, pgx.RowTo[id.ID])
			if err != nil {
				return nil, err
			}
			users, err := s.users.PublicUsers(ctx, ids)
			if err != nil {
				return nil, err
			}
			out := make([]auth.PublicUser, 0, len(ids))
			for _, u := range ids {
				out = append(out, users[u])
			}
			return &struct{ Body []auth.PublicUser }{out}, nil
		})
}
```

```ts
// Pure poll helpers: results, ending, voting and the create form. No React.
import type { Poll, PollRequest } from "@datrope/core";

export const MIN_OPTIONS = 2;
export const MAX_OPTIONS = 10;
export const MAX_QUESTION = 300;
export const MAX_OPTION = 55;

export type PollDuration = NonNullable<PollRequest["duration"]>;
export const DURATIONS: { value: PollDuration; label: string }[] = [
  { value: "1h", label: "1 hour" },
  { value: "4h", label: "4 hours" },
  { value: "8h", label: "8 hours" },
  { value: "24h", label: "24 hours" },
  { value: "3d", label: "3 days" },
  { value: "1w", label: "1 week" },
];

/** Each answer's share of the voters, in whole percent. Multiple-answer polls can add up to more than 100. */
export function percentages(poll: Pick<Poll, "options" | "total_voters">): number[] {
  const total = poll.total_voters;
  return (poll.options ?? []).map((o) => (total > 0 ? Math.round((o.count / total) * 100) : 0));
}

/** The positions with the most votes; none when nobody voted. */
export function winners(poll: Pick<Poll, "options">): number[] {
  const counts = (poll.options ?? []).map((o) => o.count);
  const top = Math.max(0, ...counts);
  return top === 0 ? [] : counts.flatMap((c, i) => (c === top ? [i] : []));
}

/** Over: ended on the server, or its end time has passed (checked locally, as the server does). */
export function isEnded(poll: Pick<Poll, "ended" | "ends_at">, now: number): boolean {
  return poll.ended || (!!poll.ends_at && Date.parse(poll.ends_at) <= now);
}

/** The time left until `endsAt`: "3d", "5h", "12m" or "<1m". */
export function timeLeft(endsAt: string, now: number): string {
  const minutes = Math.floor((Date.parse(endsAt) - now) / 60_000);
  if (minutes < 1) return "<1m";
  if (minutes < 60) return `${minutes}m`;
  const hours = Math.floor(minutes / 60);
  return hours < 24 ? `${hours}h` : `${Math.floor(hours / 24)}d`;
}

/** "N votes · ends in 3h", "N votes · Final results", or "N votes" for a poll with no end. */
export function pollFooter(poll: Pick<Poll, "total_voters" | "ended" | "ends_at">, now: number): string {
  const votes = `${poll.total_voters} ${poll.total_voters === 1 ? "vote" : "votes"}`;
  if (isEnded(poll, now)) return `${votes} · Final results`;
  return poll.ends_at ? `${votes} · ends in ${timeLeft(poll.ends_at, now)}` : votes;
}

/** My votes after clicking answer `i`: a single answer switches (or clears), multiple answers toggle. */
export function nextVotes(poll: Pick<Poll, "multi" | "my_votes">, i: number): number[] {
  const mine = poll.my_votes ?? [];
  if (mine.includes(i)) return mine.filter((p) => p !== i);
  return poll.multi ? [...mine, i].sort((a, b) => a - b) : [i];
}

export type DraftOption = { key: string; text: string; emoji?: string };
export type PollDraft = { question: string; options: DraftOption[]; multi: boolean; anonymous: boolean; duration: PollDuration | "" };

/** The request for a draft, or what is missing. Blank answers are dropped; two must remain. */
export function buildPoll(d: PollDraft): PollRequest | { error: string } {
  const question = d.question.trim();
  if (!question) return { error: "Ask a question" };
  const options = d.options.flatMap((o) => {
    const text = o.text.trim();
    return text ? [{ text, ...(o.emoji ? { emoji: o.emoji } : {}) }] : [];
  });
  if (options.length < MIN_OPTIONS) return { error: "Add at least two answers" };
  return { question, options, multi: d.multi, anonymous: d.anonymous, ...(d.duration ? { duration: d.duration } : {}) };
}

/** Moves the item at `from` by `by` places; a move past either end changes nothing. */
export function move<T>(xs: T[], from: number, by: number): T[] {
  const to = from + by;
  if (to < 0 || to >= xs.length) return xs;
  const out = [...xs];
  [out[from], out[to]] = [out[to]!, out[from]!];
  return out;
}
```

```tsx
function useNow(until: number | null): number {
  const [now, setNow] = useState(() => Date.now());
  useEffect(() => {
```

```tsx
                  onClick={() => setOptions((os) => move(os, i, -1))}><ArrowUp /></Button>
                <Button variant="ghost" size="icon-sm" aria-label={`Move answer ${i + 1} down`} disabled={i === options.length - 1}
                  onClick={() => setOptions((os) => move(os, i, 1))}><ArrowDown /></Button>
                <Button variant="ghost" size="icon-sm" aria-label={`Remove answer ${i + 1}`} disabled={options.length <= MIN_OPTIONS}
                  onClick={() => setOptions((os) => os.filter((x) => x.key !== o.key))}><X /></Button>
              </div>
            ))}
            {options.length < MAX_OPTIONS && (
              <Button variant="outline" size="sm" className="justify-self-start" onClick={() => setOptions((os) => [...os, newOption()])}>
                <Plus />Add answer
              </Button>
            )}
          </fieldset>
          <div className="flex items-center gap-2">
            <Checkbox id={multiId} checked={multi} onCheckedChange={(c) => setMulti(c === true)} />
            <Label htmlFor={multiId}>Allow multiple answers</Label>
          </div>
          <div className="flex items-center gap-2">
            <Checkbox id={anonymousId} checked={anonymous} onCheckedChange={(c) => setAnonymous(c === true)} />
            <Label htmlFor={anonymousId}>Anonymous poll</Label>
          </div>
          <Field>
            <FieldLabel htmlFor={durationId}>Duration</FieldLabel>
            <NativeSelect id={durationId} value={duration} onChange={(e) => setDuration(e.target.value as PollDuration | "")}>
              {DURATIONS.map((d) => <NativeSelectOption key={d.value} value={d.value}>{d.label}</NativeSelectOption>)}
              <NativeSelectOption value="">No end</NativeSelectOption>
            </NativeSelect>
          </Field>
          <ErrorText error={invalid ?? error} />
          <DialogFooter>
            <Button type="submit" disabled={busy}>Post poll</Button>
            <Button variant="outline" onClick={onClose}>Cancel</Button>
          </DialogFooter>
        </form>
      </DialogContent>
    </Dialog>
  );
}
```
