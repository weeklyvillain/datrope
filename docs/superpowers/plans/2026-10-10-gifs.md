# `/gif` via Klipy (piece 2) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/gif [query]` opens a GIF picker backed by Klipy. The picked GIF is downloaded by the server, stored as an ordinary attachment flagged `gif`, and posted as a normal message that plays muted and looped like an image.

**Architecture:**
- Migration 00022 adds `instance_settings.klipy_api_key`, `instance_settings.instance_secret` and `attachments.gif`.
- `auth` owns the key: it is write-only through `PATCH /api/admin/settings`; responses carry `klipy_configured` and `/api/instance` carries `gifs_enabled`.
- `files` gains `UploadLimit` (the permission and limit check the upload handler already does) and `SaveGIF` (stage plus `save`, with the `gif` flag).
- A new `gifs` package proxies Klipy (`GET /api/gifs/trending`, `GET /api/gifs/search`) and implements `POST /api/gifs/{id}/attach`. The Klipy base URL comes from `app.Config.KlipyURL`, so tests point it at an `httptest` fake.
- Web: an **Integrations** tab, a `GifMedia` renderer, the `GifDialog` modal, and the command framework additions piece 1 left out (`available`, `{ open }`).

**Tech Stack:** Go 1.25 (huma v2, pgx, testcontainers), Postgres 17, React 18, TypeScript, shadcn/ui + Tailwind v4, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-10-commands-gifs-polls-webhooks-design.md` §2 (and §1's `Command` / `CommandResult` shapes).

## Klipy API facts (verified 2026-10-10)

Sources: the `.md` versions of docs.klipy.com pages (`gifs-api/gifs-trending-api.md`, `gifs-search-api.md`, `gifs-items-api.md`, `gifs-share-trigger-api.md`, `advertisements/receiving-an-ad.md`, `attribution.md`) and the source of the `vyfor/klipy-kt` client.

- **Base URL:** `https://api.klipy.com/api/v1/{app_key}/…`. The API key is a **path segment**, so any logged request URL contains it.
- **Trending:** `GET /api/v1/{app_key}/gifs/trending`, with the query `page`, `per_page`, `customer_id`, `locale`, `format_filter`, `content_filter` (all optional).
- **Search:** `GET /api/v1/{app_key}/gifs/search`, with `q` plus the same parameters.
- **Items:** `GET /api/v1/{app_key}/gifs/items?slugs=a,b`. GIFs are looked up by **slug** in a comma-separated list. There is no lookup by numeric `id`.
- **List response:** `{"result": true, "data": {"data": [item, …], "current_page": 1, "per_page": 24, "has_next": true}}`. Items has the same envelope without the paging fields. Pagination is by page number.
- **Item:** `{"id": 8041071659142944, "slug": "hello-hi-662", "title": "Hello", "file": {SIZE: {FORMAT: {"url", "width", "height", "size"}}}, "tags": "", "type": "gif", "blur_preview": "data:image/jpeg;base64,…"}`.
  - SIZE is one of `hd`, `md`, `sm`, `xs`.
  - FORMAT is one of `gif`, `webp`, `jpg`, `mp4`, `webm`.
  - Files live on `https://static.klipy.com/…`. A typical hd MP4 is about 0.3–0.5 MB; an hd GIF is about 4 MB.
- **`customer_id`:** "A unique user identifier in your system… remains consistent for the same user." Optional.
- **Ads:** they appear in trending, search and recent only when the ad parameters are sent (`customer_id`, `ad-min-width`, `ad-max-width`, `ad-min-height`, `ad-max-height`). We send no `ad-*` parameter. An ad entry is `{"type": "ad", "content": "<html…>", "width", "height"}`. That shape comes from klipy-kt; the "displaying an ad" docs page was not read. Entries with a type other than `gif` are filtered out anyway.
- **Attribution:** the search input's placeholder must be **"Search KLIPY"** (REQUIRED). "Powered by KLIPY" is optional; the spec asks for it, so we show it.
- **Not verifiable:** the error responses (status codes and body) are not documented. We treat any non-200 status, or `result: false`, as an upstream failure. The fake Klipy in Task 4 pins the assumed shapes.

## The instance secret

No instance secret exists today. `config.go` has only LiveKit's secret, and `instance_settings` has no secret column. Migration 00022 adds one:

`instance_secret BYTEA NOT NULL DEFAULT (uuid_send(gen_random_uuid()) || uuid_send(gen_random_uuid()))`

- **Why this is sound:** `gen_random_uuid()` is built into Postgres 13+ (we run 17), so no `pgcrypto` extension is needed. It draws from the server's strong random source. Two v4 UUIDs give 32 bytes with 244 random bits.
- **When it is set:** `ALTER TABLE … ADD COLUMN … DEFAULT <volatile>` evaluates the default for the existing row, so the one `instance_settings` row gets its secret during the migration. Nothing runs at startup, operators configure nothing, and the secret survives restarts and upgrades.
- **Why the database, not an environment variable:** a new required variable would break existing deployments. A secret generated lazily in Go would need first-use races handled.
- **What it keys:** `customer_id = hex(HMAC-SHA256(instance_secret, decimal user ID))`. The secret never leaves the database through any API.
- **Tests:** test databases are cloned from one template (`pgtest`), so tests share one secret. That is harmless.

## Review Focus

1. **Non-GIF entries in Klipy lists.** Ad slots (`{"type":"ad","content":…}`), entries of another type, and entries with no usable preview must never reach the client. One must not leave a hole in the grid. Pinned in Task 3 (`TestIsGIF`, `TestPreview`) and Task 4 (`TestTrendingAndSearch`: the fake puts an ad first).
2. **The API key leaking.** The key is a URL path segment, so a transport error, an upstream error body or a log line could carry it. No response (a 502 included), no admin setting and no instance info may contain it. Pinned in Task 1 (`TestKlipyKeyIsWriteOnly`), Task 3 (`TestRedactDropsTheURL`) and Task 4 (every request helper asserts `NotContains(key)`, including the 502 paths).
3. **Klipy's declared `size` lying, or a small instance limit.** The download itself must be capped at `min(8 MB, max_upload_bytes)`. A refused GIF must leave no attachment row. Pinned in Task 4 (`TestAttachSizeCap`) and Task 3 (`TestRendition`: picks the largest rendition that claims to fit).
4. **Refusals before contacting Klipy.** A user without `AttachFiles`, a non-member, an unknown channel, or a crafted id (`cat-1,dog-2`, which would make the items lookup return two GIFs) must be refused before the server contacts Klipy, so they cannot burn the instance's Klipy quota or make it download anything. Pinned in Task 4 (`TestAttachGIF` asserts the fake saw no extra `items` request).
5. **Fast typing in the search box.** An older, slower response must not replace newer results, and a "load more" page must not be appended to a different query's results. Pinned in Task 6 (`requestTickets` tests) plus the browser check in Task 7.

```go
import (
	"bytes"

func TestSaveGIF(t *testing.T) {
	env, alice, bob, c, ch := setup(t)
	ctx := context.Background()
	svc := env.App.Files

	limit, err := svc.UploadLimit(ctx, alice.User.ID, ch)
	require.NoError(t, err)
	require.Equal(t, int64(52428800), limit)

	video := mp4Video(2048)
	a, err := svc.SaveGIF(ctx, ch, alice.User.ID, "Happy cat.mp4", bytes.NewReader(video), limit, 498, 373)
	require.NoError(t, err)
	require.True(t, a.GIF)
	require.Equal(t, "video/mp4", a.ContentType)
	require.Equal(t, "Happy cat.mp4", a.Filename)
	require.False(t, a.Inline)
	require.Equal(t, 498, *a.Width, "an MP4 keeps the provider's size")
	require.Equal(t, 373, *a.Height)

	resp, body := alice.Raw(http.MethodGet, a.URL, nil, "", http.StatusOK)
	require.Equal(t, video, body)
	require.Equal(t, "video/mp4", resp.Header.Get("Content-Type"))
	bob.Raw(http.MethodGet, a.URL, nil, "", http.StatusNotFound) // unsent: private, like any upload

	m := alice.SendWith(ch, "look", a.ID)
	require.Len(t, m.Attachments, 1)
	require.True(t, m.Attachments[0].GIF)
	var history []messages.Message
	bob.Do(http.MethodGet, "/api/channels/"+ch.String()+"/messages", nil, http.StatusOK, &history)
	found := false
	for _, h := range history {
		if h.ID == m.ID {
			require.True(t, h.Attachments[0].GIF, "the flag survives a reload")
			found = true
		}
	}
	require.True(t, found)

	// A WebP/GIF fallback is an image: it is measured, and gets no still thumbnail.
	still := pngImage(600, 500)
	img, err := svc.SaveGIF(ctx, ch, alice.User.ID, "Wave.png", bytes.NewReader(still), limit, 99, 99)
	require.NoError(t, err)
	require.True(t, img.GIF)
	require.True(t, img.Inline)
	require.Equal(t, 600, *img.Width, "the measured size wins")
	require.Empty(t, img.ThumbnailURL, "a thumbnail would stop the animation")

	// Over the limit: 413, and nothing is stored.
	_, err = svc.SaveGIF(ctx, ch, alice.User.ID, "big.mp4", bytes.NewReader(mp4Video(2048)), 1024, 1, 1)
	var he *httpx.Error
	require.ErrorAs(t, err, &he)
	require.Equal(t, http.StatusRequestEntityTooLarge, he.Status)
```

```go
package gifs

import (
	"context"
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"net/http"
	"net/url"
	"regexp"

	"github.com/datrope/datrope/server/internal/id"
)

// DefaultKlipyURL is Klipy's API. Tests point the service at a fake instead.
const DefaultKlipyURL = "https://api.klipy.com"

// errUpstream wraps every Klipy failure. Its messages never contain request
// URLs, because those carry the API key.
var errUpstream = errors.New("klipy request failed")

// maxListBody bounds a list response; a page of 24 GIFs is about 30 KB.
const maxListBody = 4 << 20

// klipyPage is Klipy's list response (trending, search, items):
// {"result": true, "data": {"data": [...], "current_page": 1, "per_page": 24, "has_next": true}}.
type klipyPage struct {
	Result bool `json:"result"`
	Data   struct {
		Data    []klipyItem `json:"data"`
		HasNext bool        `json:"has_next"`
	} `json:"data"`
}

// klipyItem is one list entry. GIFs have type "gif"; ad slots have type "ad"
// and no files.
type klipyItem struct {
	Type  string `json:"type"`
	Slug  string `json:"slug"`
	Title string `json:"title"`
	// File maps a size (hd, md, sm, xs) to its formats (gif, webp, jpg, mp4, webm).
	File map[string]map[string]klipyFile `json:"file"`
}

type klipyFile struct {
	URL    string `json:"url"`
	Width  int    `json:"width"`
	Height int    `json:"height"`
	Size   int64  `json:"size"`
}

type klipy struct {
	base   string // e.g. https://api.klipy.com
	client *http.Client
}

// list calls GET /api/v1/{key}/gifs/{endpoint}; endpoint is trending, search or items.
func (k *klipy) list(ctx context.Context, key, endpoint string, q url.Values) (*klipyPage, error) {
	u := k.base + "/api/v1/" + url.PathEscape(key) + "/gifs/" + endpoint + "?" + q.Encode()
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, u, nil)
	if err != nil {
		return nil, fmt.Errorf("%w: bad request", errUpstream)
	}
	req.Header.Set("Accept", "application/json")
	resp, err := k.client.Do(req)
	if err != nil {
		return nil, fmt.Errorf("%w: %v", errUpstream, redact(err))
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("%w: status %d", errUpstream, resp.StatusCode)
	}
	var p klipyPage
	if err := json.NewDecoder(io.LimitReader(resp.Body, maxListBody)).Decode(&p); err != nil {
		return nil, fmt.Errorf("%w: %v", errUpstream, err)
	}
	if !p.Result {
		return nil, fmt.Errorf("%w: result false", errUpstream)
	}
	return &p, nil
}

// download opens a media file. Its URL came from Klipy, never from a client.
func (k *klipy) download(ctx context.Context, rawURL string) (io.ReadCloser, error) {
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, rawURL, nil)
	if err != nil {
		return nil, fmt.Errorf("%w: bad media URL", errUpstream)
	}
	resp, err := k.client.Do(req)
	if err != nil {
		return nil, fmt.Errorf("%w: %v", errUpstream, redact(err))
	}
	if resp.StatusCode != http.StatusOK {
		resp.Body.Close()
		return nil, fmt.Errorf("%w: media status %d", errUpstream, resp.StatusCode)
	}
	return resp.Body, nil
}

// redact drops the URL from a transport error: Klipy's URLs contain the API key.
func redact(err error) error {
	var ue *url.Error
	if errors.As(err, &ue) {
		return ue.Err
	}
	return err
}

// slugPattern is what a GIF id (Klipy's slug) may look like. No commas: the
// items endpoint takes a comma-separated list.
var slugPattern = regexp.MustCompile(`^[A-Za-z0-9_-]{1,200}$`)

// isGIF reports whether a list entry is a GIF we can serve. Ad slots and
// other types are not; Klipy's docs always show type "gif" on GIFs, and an
// entry without a type is accepted.
func isGIF(it klipyItem) bool {
	return (it.Type == "gif" || it.Type == "") && slugPattern.MatchString(it.Slug)
}

var (
	sizes = []string{"hd", "md", "sm", "xs"} // largest first
	// stored lists the formats a posted GIF may be stored in, best first.
	stored = []string{"mp4", "webp", "gif"}
	// previews lists the small animated images a picker shows, best first.
	previews = [][2]string{{"sm", "webp"}, {"xs", "webp"}, {"sm", "gif"}, {"xs", "gif"}, {"md", "webp"}, {"md", "gif"}}
)

// preview picks the small animated image the picker shows.
func preview(it klipyItem) (klipyFile, bool) {
	for _, p := range previews {
		if f, ok := it.File[p[0]][p[1]]; ok && f.URL != "" {
			return f, true
		}
	}
	return klipyFile{}, false
}

// rendition picks the file to store: MP4 if any size fits under limit, else
// WebP, else GIF, and within a format the largest size that fits. A size of
// 0 (unknown) is tried; the download is capped anyway.
func rendition(it klipyItem, limit int64) (klipyFile, string, bool) {
	for _, format := range stored {
		for _, size := range sizes {
			f, ok := it.File[size][format]
			if ok && f.URL != "" && f.Size <= limit {
				return f, format, true
			}
		}
	}
	return klipyFile{}, "", false
}

// customerID is Klipy's customer_id for a user: an HMAC of the user ID keyed
// by the instance secret. Klipy can tell users apart without learning who
// they are.
func customerID(secret []byte, userID id.ID) string {
	m := hmac.New(sha256.New, secret)
	m.Write([]byte(userID.String()))
	return hex.EncodeToString(m.Sum(nil))
}
```

```go
func (f *fakeKlipy) serve(w http.ResponseWriter, r *http.Request) {
	f.mu.Lock()
	defer f.mu.Unlock()
	if strings.HasPrefix(r.URL.Path, "/media/") {
		if strings.HasSuffix(r.URL.Path, ".mp4") {
			_, _ = w.Write(f.media)
		} else {
			w.WriteHeader(http.StatusNotFound)
		}
		return
	}
	if f.down {
		w.WriteHeader(http.StatusServiceUnavailable)
		return
	}
	endpoint, ok := strings.CutPrefix(r.URL.Path, "/api/v1/"+klipyKey+"/gifs/")
	if !ok { // a wrong key
		w.WriteHeader(http.StatusUnauthorized)
		_, _ = w.Write([]byte(`{"result":false}`))
		return
	}
	q := r.URL.Query()
	w.Header().Set("Content-Type", "application/json")
	switch endpoint {
	case "trending", "search":
		f.customers = append(f.customers, q.Get("customer_id"))
		f.queries = append(f.queries, q.Get("q"))
		if q.Get("page") == "2" {
			writeList(w, []any{f.item("owl-3", "Owl")}, false)
			return
		}
		ad := map[string]any{"type": "ad", "content": "<div>Buy things</div>", "width": 300, "height": 250}
		writeList(w, []any{ad, f.item("cat-1", "Cat"), f.item("dog-2", "Dog")}, true)
	case "items":
		f.slugs = append(f.slugs, q.Get("slugs"))
		data := []any{}
		if q.Get("slugs") == "cat-1" {
			data = append(data, f.item("cat-1", "Cat"))
		}
		_ = json.NewEncoder(w).Encode(map[string]any{"result": true, "data": map[string]any{"data": data}})
	default:
		w.WriteHeader(http.StatusNotFound)
	}
}

}
```

```go
	KlipyConfig(ctx context.Context) (apiKey string, secret []byte, err error)

	SaveGIF(ctx context.Context, channelID, uploaderID id.ID, filename string, body io.Reader, limit int64, width, height int) (*files.Attachment, error)

// GIF is one trending or search result. Clients load PreviewURL straight from Klipy's CDN.
type GIF struct {
	ID         string `json:"id" doc:"Pass to POST /api/gifs/{id}/attach"`
	Title      string `json:"title"`
	PreviewURL string `json:"preview_url" doc:"A small animated WebP (or GIF) on Klipy's CDN"`
	Width      int    `json:"width"`
	Height     int    `json:"height"`
}

	Items []GIF  `json:"items"`
	Next  string `json:"next,omitempty" doc:"Pass as pos to get the next page; absent on the last page"`

	perPage     = 24
	maxPage     = 100

type Service struct {
	config      Config
	files       Files
	klipy       *klipy
	listLimit   *ratelimit.Limiter
	attachLimit *ratelimit.Limiter
}

// NewService talks to Klipy at klipyURL ("" for DefaultKlipyURL).
func NewService(cfg Config, f Files, klipyURL string) *Service {
	if klipyURL == "" {
		klipyURL = DefaultKlipyURL
	}
	return &Service{
		config:      cfg,
		files:       f,
		klipy:       &klipy{base: strings.TrimSuffix(klipyURL, "/"), client: &http.Client{Timeout: 20 * time.Second}},
		listLimit:   ratelimit.New(60, 20),
		attachLimit: ratelimit.New(10, 5),
	}

func providerError() *httpx.Error {
	return httpx.E(http.StatusBadGateway, "GIF_PROVIDER_ERROR", "couldn't reach Klipy, try again")
}

// apiKey returns the Klipy key and the instance secret. Without a key, /gif does not exist (404).
func (s *Service) apiKey(ctx context.Context) (string, []byte, error) {
	key, secret, err := s.config.KlipyConfig(ctx)
	if err != nil {
		return "", nil, err
	}
	if key == "" {
		return "", nil, httpx.NotFound("gifs")
	}
	return key, secret, nil
}

// List returns a page of search results for q, or trending GIFs when q is "".
// pos is the next value of the previous page ("" for the first).
func (s *Service) List(ctx context.Context, userID id.ID, q, pos string) (*GIFPage, error) {
	key, secret, err := s.apiKey(ctx)
	if err != nil {
		return nil, err
	}
	page := 1
	if pos != "" {
		page, err = strconv.Atoi(pos)
		if err != nil || page < 1 || page > maxPage {
			return nil, httpx.BadRequest("VALIDATION_FAILED", "pos must be a next value from a previous page")
		}
	}
	if !s.listLimit.Allow(userID.String()) {
		return nil, httpx.RateLimited()
	}
	params := url.Values{
		"page":        {strconv.Itoa(page)},
		"per_page":    {strconv.Itoa(perPage)},
		"customer_id": {customerID(secret, userID)},
	}
	endpoint := "trending"
	if q != "" {
		endpoint = "search"
		params.Set("q", q)
	}
	p, err := s.klipy.list(ctx, key, endpoint, params)
	if err != nil {
		slog.WarnContext(ctx, "gifs: list", "endpoint", endpoint, "err", err)
		return nil, providerError()
	}
	out := &GIFPage{Items: []GIF{}}
	for _, it := range p.Data.Data {
		if !isGIF(it) { // ad slots and other kinds of content
			continue
		}
		f, ok := preview(it)
		if !ok {
			continue
		}
		out.Items = append(out.Items, GIF{ID: it.Slug, Title: it.Title, PreviewURL: f.URL, Width: f.Width, Height: f.Height})
	}
	if p.Data.HasNext && page < maxPage {
		out.Next = strconv.Itoa(page + 1)
	}
	return out, nil
}

// Attach looks the GIF up with Klipy by its id, downloads its best rendition
// that fits and stores it as an unsent attachment in channelID. It never
// fetches a URL a client supplied.
func (s *Service) Attach(ctx context.Context, userID, channelID id.ID, slug string) (*files.Attachment, error) {
	key, _, err := s.apiKey(ctx)
	if err != nil {
		return nil, err
	}
	if !slugPattern.MatchString(slug) {
		return nil, httpx.NotFound("gif")
	}
	limit, err := s.files.UploadLimit(ctx, userID, channelID)
	if err != nil {
		return nil, err
	}
	limit = min(limit, maxGIFBytes)
	if !s.attachLimit.Allow(userID.String()) {
		return nil, httpx.RateLimited()
	}
	p, err := s.klipy.list(ctx, key, "items", url.Values{"slugs": {slug}})
	if err != nil {
		slog.WarnContext(ctx, "gifs: look up", "err", err)
		return nil, providerError()
	}
	var item *klipyItem
	for i := range p.Data.Data {
		if it := &p.Data.Data[i]; isGIF(*it) && it.Slug == slug {
			item = it
			break
		}
	}
	if item == nil {
		return nil, httpx.NotFound("gif")
	}
	f, format, ok := rendition(*item, limit)
	if !ok {
		return nil, httpx.E(http.StatusRequestEntityTooLarge, "TOO_LARGE", fmt.Sprintf("this GIF is over the %d-byte limit", limit))
	}
	rc, err := s.klipy.download(ctx, f.URL)
	if err != nil {
		slog.WarnContext(ctx, "gifs: download", "err", err)
		return nil, providerError()
	}
	defer rc.Close()
	body := &tracked{r: rc}
	name := strings.TrimSpace(item.Title)
	if name == "" {
		name = slug
	}
	a, err := s.files.SaveGIF(ctx, channelID, userID, name+"."+format, body, limit, f.Width, f.Height)
	if err != nil && body.err != nil { // the download broke off: Klipy's fault, not ours
		slog.WarnContext(ctx, "gifs: download", "err", redact(body.err))
		return nil, providerError()
	}
	return a, err
}

// tracked remembers a read error from the download, so a broken download is
// reported as a provider error rather than an internal one.
type tracked struct {
	r   io.Reader
	err error
}

func (t *tracked) Read(p []byte) (int, error) {
	n, err := t.r.Read(p)
	if err != nil && !errors.Is(err, io.EOF) {
		t.err = err
	}
	return n, err
}
```

```ts
// Pure helpers for the GIF picker (app/GifDialog.tsx).
import { ApiError } from "@datrope/core";

/** Splits items into columns, each into the column that is currently shortest
 *  (by height / width, so a column's width doesn't matter). Order is kept within a column. */
export function masonry<T extends { width: number; height: number }>(items: T[], columns: number): T[][] {
  const cols: T[][] = Array.from({ length: columns }, () => []);
  const heights: number[] = Array.from({ length: columns }, () => 0);
  for (const item of items) {
    const i = heights.indexOf(Math.min(...heights));
    cols[i]!.push(item);
    heights[i] = heights[i]! + (item.width > 0 && item.height > 0 ? item.height / item.width : 1);
  }
  return cols;
}

/** items followed by the ones in more that are not already listed. */
export function appendUnique<T extends { id: string }>(items: T[], more: T[]): T[] {
  const seen = new Set(items.map((x) => x.id));
  return [...items, ...more.filter((x) => !seen.has(x.id) && !!seen.add(x.id))];
}

/** Tickets for requests whose answers may arrive out of order: only the newest is used. */
export function requestTickets() {
  let newest = 0;
  return {
    /** A ticket for a request that replaces everything before it (a new search). */
    renew: () => ++newest,
    /** A ticket for a request that continues the newest one (its next page). */
    current: () => newest,
    isNewest: (ticket: number) => ticket === newest,
  };
}

/** What to say when storing the picked GIF fails. */
export function attachError(e: unknown): string {
  if (!(e instanceof ApiError)) return "Something went wrong. Please try again.";
  if (e.code === "TOO_LARGE") return "That GIF is too big to post here. Try another one.";
  if (e.code === "RATE_LIMITED") return "You're sending GIFs too fast. Wait a moment and try again.";
  if (e.code === "GIF_PROVIDER_ERROR") return "Couldn't reach Klipy. Try again.";
  return e.message;
}
```

```tsx
const COLUMNS = 3;
const DEBOUNCE_MS = 300;

function useDebounced<T>(value: T, ms: number): T {
  const [settled, setSettled] = useState(value);
  useEffect(() => {
    const t = setTimeout(() => setSettled(value), ms);
    return () => clearTimeout(t);
  }, [value, ms]);
  return settled;
}

type Results = { items: GIF[]; next?: string; loading: boolean; failed: boolean };

/** Search results (trending for an empty query), page by page. Only the newest request's answer is used. */
function useGifResults(query: string) {
  const [results, setResults] = useState<Results>({ items: [], loading: true, failed: false });
  const [tickets] = useState(requestTickets);
  const load = useCallback((pos?: string) => {
    const ticket = pos ? tickets.current() : tickets.renew();
    setResults((r) => (pos ? { ...r, loading: true, failed: false } : { items: [], loading: true, failed: false }));
    const q = query.trim();
    const page = q
      ? unwrap(client.api.GET("/api/gifs/search", { params: { query: pos ? { q, pos } : { q } } }))
      : unwrap(client.api.GET("/api/gifs/trending", { params: { query: pos ? { pos } : {} } }));
    page.then(
      (p) => {
        if (!tickets.isNewest(ticket)) return;
        setResults((r) => ({ items: appendUnique(pos ? r.items : [], p.items ?? []), next: p.next, loading: false, failed: false }));
      },
      () => {
        if (tickets.isNewest(ticket)) setResults((r) => ({ ...r, loading: false, failed: true }));
      },
    );
  }, [query, tickets]);
  useEffect(() => load(), [load]);
  return { ...results, load };
}

/** Calls onVisible once it scrolls into view, or on mount if it is already visible. */
function Sentinel({ onVisible }: { onVisible: () => void }) {
  const ref = useRef<HTMLDivElement>(null);
  const latest = useRef(onVisible);
  latest.current = onVisible;
  useEffect(() => {
    const el = ref.current;
    if (!el) return;
    const io = new IntersectionObserver((entries) => {
      if (entries.some((e) => e.isIntersecting)) latest.current();
    }, { rootMargin: "200px" });
    io.observe(el);
    return () => io.disconnect();
  }, []);
  return <div ref={ref} aria-hidden="true" className="h-px" />;
}

    setChosen(g);
    setCaption("");
    setSendError(undefined);

            <FormField label="Caption" placeholder="Add a caption (optional)" maxLength={4000} autoFocus

            <ErrorText error={sendError} />
            <DialogFooter>

              <Button type="submit" disabled={sending}>Send</Button>
            </DialogFooter>
          </form>
        ) : (
          <>
            <Input aria-label="Search GIFs" placeholder="Search KLIPY" value={text} maxLength={100} autoFocus

                  <Button variant="outline" onClick={() => results.load(results.items.length > 0 ? results.next : undefined)}>Retry</Button>
                </div>
              )}
              {results.loading && <p role="status" className="py-6 text-center text-muted-foreground">Loading…</p>}
              {!results.loading && !results.failed && results.items.length === 0 && (
                <p className="py-6 text-center text-muted-foreground">No GIFs found</p>
              )}
              {results.next && !results.loading && !results.failed && (
                <Sentinel key={results.next} onVisible={() => results.load(results.next)} />
              )}
            </div>
          </>
        )}
        <p className="text-right text-xs text-muted-foreground">Powered by KLIPY</p>
      </DialogContent>
    </Dialog>
  );
}
```

Notes for the implementer:
- `Sentinel` is keyed by `next` and mounts only between loads, so each page gets a fresh observer. An observer fires once on mount when the sentinel is already visible, which fills a short first page.
- Going **Back** keeps the query and the loaded results: the grid's state lives in `GifDialog`.
- If `p.items` is typed non-nullable in the generated schema, `?? []` is still fine (TS allows it). If the typecheck complains about the `{}` trending query, use `{ params: { query: pos ? { pos } : undefined } }`.
