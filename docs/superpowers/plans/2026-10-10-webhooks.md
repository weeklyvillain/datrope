# Webhook Channels (piece 4) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only **Webhook** channel type. Services outside Datrope post into it with Discord's execute-webhook format (`POST /api/webhooks/{id}/{token}`), including rich embeds and remote images, which the server downloads and serves itself.

**Architecture:**
- **Server, schema.** Migration `00024` adds the `webhook` channel type, the `webhooks` table, nullable `messages.author_id` plus webhook author columns and an `embeds` column, and a `message_images` table. `message_images` holds the blobs of webhook avatars and embed images on messages, keeps them out of the sweep, and decides who may fetch them.
- **Server, permissions.** New flag `ManageWebhooks` (`1 << 21`). `channels.Service.Perms` (and with it `Access`) clears `SendMessages | AttachFiles` in a `webhook` channel for everyone, the owner included. Threads compute their permissions from the parent's unmasked `permsIn`, so they are unaffected. The web client mirrors this in `myChannelPerms`, and a new `myThreadPerms` is used for threads.
- **Server, packages.** The `messages` package learns webhook-authored messages: `Author` becomes a pointer, plus `Webhook` and `Embeds` fields, `PostWebhook`, and the image route. A new `webhooks` package owns CRUD, avatars, the execute handler (a plain `mux` handler with Discord-shaped errors), embed validation and the remote image fetcher. The fetcher reuses linkpreview's guarded client through a new `linkpreview.NewClient`.
- **Web.** The new channel type appears in Create Channel, the sidebar and routing. Channel settings gets a Webhooks tab. Messages show the webhook's name, avatar, a WEBHOOK badge and a small popover. A new `WebhookEmbeds` component renders embeds.

**Tech Stack:** Go 1.25 (huma v2, pgx v5, goose), Postgres, React 18, TypeScript, shadcn/ui (Radix, Tailwind v4 tokens), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-10-commands-gifs-polls-webhooks-design.md` §4 (Webhook channels). Where this plan disagrees with the spec, the decision and the reason are stated in "Decisions that correct or extend the spec" below.

## Decisions that correct or extend the spec

1. **No `LEFT JOIN users`.** No query joins `users`. `scanMessage` scans `author_id`, and `withAuthors` fills authors through `Users.PublicUsers`. Instead:
   - `Message.Author` becomes `*auth.PublicUser` and `scanMessage` scans `author_id` as nullable.
   - A NULL `author_id` produces `Message.Webhook` (`WebhookAuthor{id?, name, avatar_url?}`) from the message's own columns.
   - `withAuthors` skips webhook messages.
   - Every other site is audited:
     - `inbox.go`: `m.author_id <> $1` becomes `IS DISTINCT FROM`. Otherwise a webhook mention never reaches the inbox, because `NULL <> x` is NULL.
     - `replies.go`: scans a nullable author and shows the webhook's name.
     - `threads.go`: thread summaries skip NULL authors.
     - `handlers.go`: edit refuses webhook messages. Delete needs `ManageMessages` and skips the hierarchy check.
     - `search.go`: `from:` needs no change.
     - Core store: optimistic messages keep `author`; `m.author.id` becomes optional chaining.
     - Web: `MessageList`, `ReplyQuote` (unchanged: `ReplyRef.author` stays required), `PinsPanel`, `SearchPanel`, `InboxButton`, `ThreadPanel`, `NotificationListener`, `notify.ts`, `unread.ts` and `sounds.ts`.
2. **`author` and `webhook` are absent, not `null`.** Both use `omitempty`, which is how this API marks optional fields (`edited_at`, `reply_to`, `embed`). In TypeScript they are `author?:` and `webhook?:`. `webhook.id` is also optional: it disappears when the webhook is deleted (`ON DELETE SET NULL`). `webhook.avatar_url` is absent when there is none.
3. **Embeds are named apart from link previews.** `Message.Embed` (JSONB `embed`, the link preview, TS type `Embed`) already exists. Webhook embeds are `Message.Embeds` (JSONB `embeds`), with Go type `messages.WebhookEmbed` and TS type `WebhookEmbed`. The web component is `WebhookEmbeds` / `WebhookEmbedCard` in `src/app/WebhookEmbed.tsx`, not `Embed`.
4. **Where the mask lives.**
   - Server: in `channels.Service.Perms`, after `permsIn`. `Access`, uploads, typing and voice all go through it. `permsIn`, which threads use for their parent, stays unmasked.
   - `overrideTarget` checks "you may only set bits you hold" against the unmasked permissions. Otherwise even the owner could not set a `SendMessages` override on a webhook channel, and those overrides govern its threads.
   - Create-thread checks `CreateThreads` in the channel and `SendMessages` in the would-be thread, through the new `channels.Service.ThreadPerms`.
   - Client: `myChannelPerms` masks, and the new `myThreadPerms` does not. `ThreadPanel` and `ChannelView`'s thread check use `myThreadPerms`.
5. **Avatars are uploaded separately.** They are not part of the create or PATCH JSON. They use `PUT/DELETE /api/webhooks/{id}/avatar` (multipart `file`), like user avatars. They are served at `GET /api/webhooks/{id}/avatar` behind a session and a ViewChannel check. Create and PATCH take `{ name }` only.
6. **Images on messages.** A webhook message's avatar and its embed images become rows of `message_images(message_id, sha256, content_type)`. The table is registered with `files.AddBlobTable`, and the sweep finds its rows through an index on `sha256`. `messages.author_avatar_sha256` (from the spec) records which of them is the avatar. It is not a blob table: that would scan `messages`. Images are served at `GET /api/messages/{messageID}/images/{sha256}` behind a session, with ReadHistory on the message's channel (404 otherwise) and `Cache-Control: private`. `webhooks.avatar_content_type` is added so avatars can be served with their type.
7. **The spec's "role mentions" don't exist on this server.** It only parses user mentions; there is no `@everyone`, `@here` or role mention to suppress. Decision: a webhook message drops the usernames `everyone` and `here` from its mentions, so a user with either name is never pinged that way. Other user mentions notify and land in the inbox.
8. **Execute is a plain `mux` handler, not huma.**
   - It has no session. Like the LiveKit webhook, the credential is in the request.
   - Huma rejects unknown JSON fields (`additionalProperties: false`), and Discord payloads carry many (`tts`, `allowed_mentions`, `components`, `embeds[].type`).
   - It must answer Discord's numeric error codes, not `httpx.Error`'s string codes.
   - The codes: `404 {code: 10015, "Unknown Webhook"}`, `401 {50027, "Invalid Webhook Token"}`, `400 {50035, "Invalid Form Body: …"}`, `400 {50006, "Cannot send an empty message"}`, `400 {50109, invalid JSON}` and `413 {40005}` above 1 MB. A 429 has `Retry-After: 2` and `{code: 0, message, retry_after: 2}`.
   - `?wait=true` returns Datrope's `Message` JSON, not Discord's message object.
   - Only JSON bodies are accepted. Discord's `multipart/form-data` (`payload_json` with files) is out of scope and gets 50109.
9. **Rate limit.** `ratelimit.New(30, 30)` per webhook ID, checked after the token, so strangers cannot use up a webhook's budget.
10. **The token** is `auth.NewToken()` (32 random bytes, base64url). Only `auth.HashToken(token)` is stored. Execute compares `HashToken(given)` to the stored hash with `subtle.ConstantTimeCompare`.
11. **Image fetcher.** `linkpreview` exports `NewClient(allow, timeout)`, `Public` and `ErrBlockedAddress`, and `fetchWith` uses them. The webhooks fetcher uses the same client:
    - images are downloaded in parallel, 5 s each, 10 s in all;
    - the avatar counts toward the 12;
    - a `Content-Type` other than the four image types, a body over 2 MB, a non-200 answer, or a body `files.StoreImageBlob` cannot read: the image is dropped.
12. **Extensions the spec is silent on**, kept small:
    - every URL field must be `http(s)` (no `javascript:` links in embeds);
    - an embed must have something in it;
    - embed timestamps are normalised to RFC 3339 UTC;
    - `content` and `username` are trimmed.
13. **Where webhook channels count like text channels.** `channels.Readable` and search's `in:` include webhook channels. The sidebar marks them unread, they open in `ChannelView`, and their threads work. Voice join refuses them (`NOT_VOICE_CHANNEL`).
14. **Limits of the UI and events.**
    - The Webhooks tab lives in Channel settings, which the sidebar only offers to people with ManageChannels. Someone with only ManageWebhooks can use the API but has no UI. That is accepted for now.
    - Webhook CRUD publishes no gateway events; the tab reloads the list when it opens.

## Review Focus

1. **A webhook message from a webhook that was later renamed or deleted, or that has no avatar.** It must still render with its stored name, no ID and the webhook icon. Two such consecutive messages must still group. Pinned in Task 4 (`TestWebhookLifecycle`) and Task 6 (`authorKey` tests).
2. **The owner and admins in a webhook channel.** They must be refused posting, uploading and typing at the top level. They can still read, start threads, post in threads, and set a `SendMessages` override that governs the threads. Pinned in Task 1 (`TestWebhookChannel`).
3. **A hostile embed.** A `javascript:` link, a `file://` image, an `ftp://` avatar, or limits off by one must get a Discord-shaped 400, never a stored message. Pinned in Task 4 (`TestExecuteLimits`, both sides of every limit).
4. **Mentions from a webhook.** `@everyone` and `@here` must never ping anyone, even users named "everyone" or "here". `@bob` must reach bob's inbox even though the message has no author. Pinned in Task 4 (`TestExecuteMentions`) and Task 2 (inbox assertion).
5. **Remote images.**
   - These must be refused: loopback, private, link-local and metadata addresses, and redirects onto them.
   - These are dropped while the message still posts: non-images, images over 2 MB, and 404s.
   - Clients never see a remote URL.

   Pinned in Task 5 (`TestFetchImage*`, `TestExecuteFetchesImages`).

func TestWebhookChannel(t *testing.T) {
	env := apptest.New(t)
	alice := env.Register("alice") // the owner: every permission
	bob := env.Register("bob")
	srv := alice.Server()

	var hook channels.Channel
	alice.Do(http.MethodPost, "/api/server/channels", map[string]any{"name": "alerts", "type": "webhook"}, http.StatusCreated, &hook)
	require.Equal(t, channels.TypeWebhook, hook.Type)
	bob.Fail(http.MethodPost, "/api/server/channels", map[string]any{"name": "x", "type": "webhook"}, http.StatusForbidden, "MISSING_PERMISSION")
	alice.Fail(http.MethodPost, "/api/server/channels", map[string]any{"name": "x", "type": "thread"}, http.StatusBadRequest, "VALIDATION_FAILED")

	path := "/api/channels/" + hook.ID.String()
	// Nobody posts, uploads or types at the top level, the owner included.
	for _, c := range []*apptest.Client{alice, bob} {
		c.Fail(http.MethodPost, path+"/messages", map[string]any{"content": "hi"}, http.StatusForbidden, "MISSING_PERMISSION")
		c.Fail(http.MethodPost, path+"/typing", nil, http.StatusForbidden, "MISSING_PERMISSION")
		c.UploadFail(hook.ID, "a.txt", []byte("a"), http.StatusForbidden, "MISSING_PERMISSION")
	}
	bob.Do(http.MethodGet, path+"/messages", nil, http.StatusOK, nil) // reading works

	// Its messages are searchable: Readable and in: include webhook channels.
	first := insertMessage(t, env, hook.ID, alice.User.ID, "deploy finished")
	var res messages.SearchResponse
	bob.Do(http.MethodGet, "/api/search?q=deploy", nil, http.StatusOK, &res)
	require.Len(t, res.Results, 1)
	bob.Do(http.MethodGet, "/api/search?q=deploy+in:alerts", nil, http.StatusOK, &res)
	require.Len(t, res.Results, 1)

	// A thread under it is an ordinary thread: the mask does not apply there.
	var thread channels.Channel
	bob.Do(http.MethodPost, path+"/messages/"+first.String()+"/thread", map[string]any{}, http.StatusCreated, &thread)
	alice.Send(thread.ID, "nice")
	bob.Send(thread.ID, "agreed")
	bob.Upload(thread.ID, "notes.txt", []byte("notes"), http.StatusCreated)

	// Its overrides still govern its threads, and the owner can set SEND_MESSAGES on it:
	// the mask does not count against "you can only allow or deny what you hold".
	alice.Do(http.MethodPut, path+"/overrides/role/"+srv.ID.String(),
		map[string]any{"allow": 0, "deny": uint64(perms.SendMessages)}, http.StatusOK, nil)
	bob.Fail(http.MethodPost, "/api/channels/"+thread.ID.String()+"/messages", map[string]any{"content": "x"},
		http.StatusForbidden, "MISSING_PERMISSION")
	second := insertMessage(t, env, hook.ID, alice.User.ID, "deploy failed")
	bob.Fail(http.MethodPost, path+"/messages/"+second.String()+"/thread", map[string]any{}, http.StatusForbidden, "MISSING_PERMISSION")
	alice.Do(http.MethodPost, path+"/messages/"+second.String()+"/thread", map[string]any{}, http.StatusCreated, nil)
}

// insertMessage stores a message directly: nobody can post in a webhook channel through the API.
func insertMessage(t *testing.T, env *apptest.Env, channelID, authorID id.ID, content string) id.ID {
	t.Helper()
	mid := id.New()
	_, err := env.Pool.Exec(context.Background(), `INSERT INTO messages (id, channel_id, author_id, content) VALUES ($1, $2, $3, $4)`,
		mid, channelID, authorID, content)
	require.NoError(t, err)
	return mid
}

-- +goose Up
ALTER TABLE channels DROP CONSTRAINT channels_type_check;
ALTER TABLE channels ADD CONSTRAINT channels_type_check CHECK (type IN ('text', 'voice', 'welcome', 'dm', 'thread', 'webhook'));

-- Incoming webhooks. Only the token's SHA-256 is stored, like sessions.
CREATE TABLE webhooks (
    id                  BIGINT PRIMARY KEY,
    channel_id          BIGINT NOT NULL REFERENCES channels (id) ON DELETE CASCADE,
    name                TEXT NOT NULL,
    avatar_sha256       TEXT,
    avatar_content_type TEXT,
    token_hash          BYTEA NOT NULL,
    created_by          BIGINT REFERENCES users (id) ON DELETE SET NULL,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX webhooks_channel_idx ON webhooks (channel_id);
CREATE INDEX webhooks_avatar_sha_idx ON webhooks (avatar_sha256) WHERE avatar_sha256 IS NOT NULL;

-- A webhook message has no author: it keeps the name and avatar it was posted
-- with, so renaming or deleting the webhook does not change it.
ALTER TABLE messages
    ALTER COLUMN author_id DROP NOT NULL,
    ADD COLUMN webhook_id           BIGINT REFERENCES webhooks (id) ON DELETE SET NULL,
    ADD COLUMN author_name          TEXT NOT NULL DEFAULT '',
    ADD COLUMN author_avatar_sha256 TEXT,
    ADD COLUMN embeds               JSONB,
    ADD CONSTRAINT messages_has_author CHECK (author_id IS NOT NULL OR author_name <> '');
CREATE INDEX messages_webhook_idx ON messages (webhook_id) WHERE webhook_id IS NOT NULL;

-- Every image a message shows that is not an attachment: a webhook message's
-- avatar and embed images. Its rows keep their blobs alive and say who may
-- fetch them (readers of the message's channel).
CREATE TABLE message_images (
    message_id   BIGINT NOT NULL REFERENCES messages (id) ON DELETE CASCADE,
    sha256       TEXT NOT NULL,
    content_type TEXT NOT NULL,
    PRIMARY KEY (message_id, sha256)
);
CREATE INDEX message_images_sha_idx ON message_images (sha256);

-- +goose Down
DROP TABLE message_images;
DELETE FROM messages WHERE author_id IS NULL;
DROP INDEX messages_webhook_idx;
ALTER TABLE messages
    DROP CONSTRAINT messages_has_author,
    DROP COLUMN embeds,
    DROP COLUMN author_avatar_sha256,
    DROP COLUMN author_name,
    DROP COLUMN webhook_id,
    ALTER COLUMN author_id SET NOT NULL;
DROP TABLE webhooks;
DELETE FROM channels WHERE type = 'webhook';
ALTER TABLE channels DROP CONSTRAINT channels_type_check;
ALTER TABLE channels ADD CONSTRAINT channels_type_check CHECK (type IN ('text', 'voice', 'welcome', 'dm', 'thread'));

		}

		} else { // a webhook message (nobody can reply in a webhook channel today): show its name

		}
		refs[r.ID] = r
	}

		return err
	}

		return err
	}

		if ms[i].replyToID == nil {
			continue
		}

			if r.Author.ID != 0 {
				r.Author = users[r.Author.ID]
			}
			ms[i].ReplyTo = r
		}
	}

	}

	h.Set("X-Content-Type-Options", "nosniff")

// Package webhooks owns incoming webhooks: secret URLs that services outside
// Datrope post Discord-style messages to, each into one webhook channel.
package webhooks

import (
	"context"
	"errors"
	"log/slog"
	"net/http"
	"strings"
	"time"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"

	"github.com/datrope/datrope/server/internal/auth"
	"github.com/datrope/datrope/server/internal/channels"
	"github.com/datrope/datrope/server/internal/httpx"
	"github.com/datrope/datrope/server/internal/id"
	"github.com/datrope/datrope/server/internal/perms"
)

// Channels is what this package needs from channels.
type Channels interface {
	Access(ctx context.Context, userID, channelID id.ID, need perms.Perms) (*channels.Channel, perms.Perms, error)
}

// Blobs is what this package needs from files: cleaned, stored images.
type Blobs interface {
	StoreImageBlob(ctx context.Context, tx pgx.Tx, data []byte) (sum, contentType string, err error)
	ImageSize(data []byte) (width, height int, err error)
	RemoveBlobs(ctx context.Context, sums []string) error
	ServePrivateBlob(w http.ResponseWriter, r *http.Request, sum, contentType string)
}

type Webhook struct {
	ID        id.ID     `json:"id"`
	ChannelID id.ID     `json:"channel_id"`
	Name      string    `json:"name"`
	AvatarURL string    `json:"avatar_url,omitempty" doc:"Absent when it has none; clients draw the webhook icon"`
	CreatedBy *id.ID    `json:"created_by,omitempty"`
	CreatedAt time.Time `json:"created_at"`
}

// WebhookWithURL is a webhook with its secret. Only create and regenerate
// return it: the token is not stored, only its SHA-256.
type WebhookWithURL struct {
	Webhook
	Token string `json:"token" doc:"Shown once"`
	URL   string `json:"url" doc:"POST Discord-style messages here; shown once"`
}

type Service struct {
	db        *pgxpool.Pool
	channels  Channels
	blobs     Blobs
	publicURL string
}

func NewService(pool *pgxpool.Pool, c Channels, b Blobs, publicURL string) *Service {
	return &Service{db: pool, channels: c, blobs: b, publicURL: strings.TrimSuffix(publicURL, "/")}
}

const webhookCols = `id, channel_id, name, avatar_sha256, created_by, created_at`

func scanWebhook(row pgx.Row) (*Webhook, error) {
	var w Webhook
	var avatar *string
	var createdBy *int64
	if err := row.Scan(&w.ID, &w.ChannelID, &w.Name, &avatar, &createdBy, &w.CreatedAt); err != nil {
		return nil, err
	}
	w.CreatedBy = id.FromNullable(createdBy)
	if avatar != nil && len(*avatar) >= 12 {
		w.AvatarURL = "/api/webhooks/" + w.ID.String() + "/avatar?v=" + (*avatar)[:12]
	}
	return &w, nil
}

// withSecret adds the token and the execute URL built from it.
func (s *Service) withSecret(w *Webhook, token string) *WebhookWithURL {
	return &WebhookWithURL{Webhook: *w, Token: token, URL: s.publicURL + "/api/webhooks/" + w.ID.String() + "/" + token}
}

// channel loads a channel the signed-in user may manage webhooks in.
func (s *Service) channel(ctx context.Context, raw string) (*channels.Channel, error) {
	chID, err := httpx.ParseID(raw, "channel")
	if err != nil {
		return nil, err
	}
	ch, _, err := s.channels.Access(ctx, auth.Current(ctx).User.ID, chID, perms.ManageWebhooks)
	return ch, err
}

// manageable loads a webhook the signed-in user may manage: MANAGE_WEBHOOKS
// in its channel. One in a channel they cannot see is reported as missing.
func (s *Service) manageable(ctx context.Context, raw string) (*Webhook, error) {
	wid, err := httpx.ParseID(raw, "webhook")
	if err != nil {
		return nil, err
	}
	w, err := scanWebhook(s.db.QueryRow(ctx, `SELECT `+webhookCols+` FROM webhooks WHERE id = $1`, wid))
	if errors.Is(err, pgx.ErrNoRows) {
		return nil, httpx.NotFound("webhook")
	}
	if err != nil {
		return nil, err
	}
	if _, _, err := s.channels.Access(ctx, auth.Current(ctx).User.ID, w.ChannelID, perms.ManageWebhooks); err != nil {
		var he *httpx.Error
		if errors.As(err, &he) && he.Status == http.StatusNotFound {
			return nil, httpx.NotFound("webhook")
		}
		return nil, err
	}
	return w, nil
}

// removeBlob drops an avatar blob nothing uses any more; the sweep retries failures.
func (s *Service) removeBlob(ctx context.Context, sum string) {
	if err := s.blobs.RemoveBlobs(ctx, []string{sum}); err != nil {
		slog.WarnContext(ctx, "webhooks: removing an old avatar; the sweep will retry", "err", err)
	}
}

	ID string `path:"id"`

// cleanName trims a webhook name; a blank one is refused.
func cleanName(raw string) (string, error) {
	name := strings.TrimSpace(raw)
	if name == "" {
		return "", httpx.BadRequest("VALIDATION_FAILED", "a webhook needs a name")
	}
	return name, nil
}

func Register(api huma.API, s *Service) {
	tags := []string{"webhooks"}
	op := func(opID, method, path string, status int) huma.Operation {
		return huma.Operation{OperationID: opID, Method: method, Path: path, Tags: tags, Security: httpx.Authed, DefaultStatus: status}
	}

	huma.Register(api, op("list-webhooks", http.MethodGet, "/api/channels/{id}/webhooks", 0),
		func(ctx context.Context, in *pathID) (*struct{ Body []Webhook }, error) {
			ch, err := s.channel(ctx, in.ID)
			if err != nil {
				return nil, err
			}
			rows, err := s.db.Query(ctx, `SELECT `+webhookCols+` FROM webhooks WHERE channel_id = $1 ORDER BY id`, ch.ID)
			if err != nil {
				return nil, err
			}
			defer rows.Close()
			out := []Webhook{}
			for rows.Next() {
				w, err := scanWebhook(rows)
				if err != nil {
					return nil, err
				}
				out = append(out, *w)
			}
			return &struct{ Body []Webhook }{out}, rows.Err()
		})

	huma.Register(api, op("create-webhook", http.MethodPost, "/api/channels/{id}/webhooks", http.StatusCreated),
		func(ctx context.Context, in *struct {
			ID   string `path:"id"`
			Body WebhookRequest
		}) (*struct{ Body *WebhookWithURL }, error) {
			ch, err := s.channel(ctx, in.ID)
			if err != nil {
				return nil, err
			}
			if ch.Type != channels.TypeWebhook {
				return nil, httpx.BadRequest("NOT_A_WEBHOOK_CHANNEL", "webhooks can only be added to webhook channels")
			}
			name, err := cleanName(in.Body.Name)
			if err != nil {
				return nil, err
			}
			token, hash, err := auth.NewToken()
			if err != nil {
				return nil, err
			}
			w, err := scanWebhook(s.db.QueryRow(ctx, `
				INSERT INTO webhooks (id, channel_id, name, token_hash, created_by) VALUES ($1, $2, $3, $4, $5)
				RETURNING `+webhookCols, id.New(), ch.ID, name, hash, auth.Current(ctx).User.ID))
			if err != nil {
				return nil, err
			}
			return &struct{ Body *WebhookWithURL }{s.withSecret(w, token)}, nil
		})

	huma.Register(api, op("update-webhook", http.MethodPatch, "/api/webhooks/{id}", 0),
		func(ctx context.Context, in *struct {

			}

const (
	maxAvatarBytes = 512 << 10 // as for user avatars
	maxAvatarSide  = 1024
)

// readAvatar reads and checks the multipart "file" field: size, image type and dimensions.
func (s *Service) readAvatar(w http.ResponseWriter, r *http.Request) ([]byte, error) {
	tooLarge := httpx.E(http.StatusRequestEntityTooLarge, "TOO_LARGE", "avatars can be at most 512 KB")
	limit := int64(maxAvatarBytes) + 64<<10
	r.Body = http.MaxBytesReader(w, r.Body, limit)
	if err := r.ParseMultipartForm(limit); err != nil {
		var tooBig *http.MaxBytesError
		if errors.As(err, &tooBig) {
			return nil, tooLarge
		}
		return nil, httpx.BadRequest("VALIDATION_FAILED", "expected a multipart/form-data body")
	}
	defer func() { _ = r.MultipartForm.RemoveAll() }()
	f, _, err := r.FormFile("file")
	if err != nil {
		return nil, httpx.BadRequest("MISSING_FILE", `the form has no "file" field`)
	}
	defer f.Close()
	data, err := io.ReadAll(io.LimitReader(f, maxAvatarBytes+1))
	if err != nil {
		return nil, err
	}
	if len(data) > maxAvatarBytes {
		return nil, tooLarge
	}
	width, height, err := s.blobs.ImageSize(data)
	if err != nil {
		return nil, httpx.BadRequest("NOT_AN_IMAGE", "upload a PNG, JPEG, WebP or GIF image")
	}
	if width > maxAvatarSide || height > maxAvatarSide {
		return nil, httpx.BadRequest("IMAGE_TOO_BIG", "avatars can be at most 1024 × 1024 pixels")
	}
	return data, nil
}

func writeWebhook(w http.ResponseWriter, r *http.Request, hook *Webhook, err error) {
	if err != nil {
		httpx.WriteHTTPError(w, r, err)
		return
	}
	httpx.WriteJSON(w, http.StatusOK, hook)
}

// AvatarUploadHandler serves PUT /api/webhooks/{id}/avatar (multipart
// "file"). It must run behind auth.RequireHTTP.
func (s *Service) AvatarUploadHandler() http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		hook, err := s.uploadAvatar(w, r)
		writeWebhook(w, r, hook, err)
	})
}

func (s *Service) uploadAvatar(w http.ResponseWriter, r *http.Request) (*Webhook, error) {
	ctx := r.Context()
	hook, err := s.manageable(ctx, r.PathValue("id"))
	if err != nil {
		return nil, err
	}
	data, err := s.readAvatar(w, r)
	if err != nil {
		return nil, err
	}
	tx, err := s.db.Begin(ctx)
	if err != nil {
		return nil, err
	}
	defer tx.Rollback(ctx)
	var old *string
	if err := tx.QueryRow(ctx, `SELECT avatar_sha256 FROM webhooks WHERE id = $1 FOR UPDATE`, hook.ID).Scan(&old); err != nil {
		if errors.Is(err, pgx.ErrNoRows) {
			return nil, httpx.NotFound("webhook")
		}
		return nil, err
	}
	sum, ct, err := s.blobs.StoreImageBlob(ctx, tx, data) // sniffs the type and strips metadata
	if err != nil {
		return nil, err
	}
	updated, err := scanWebhook(tx.QueryRow(ctx,
		`UPDATE webhooks SET avatar_sha256 = $2, avatar_content_type = $3 WHERE id = $1 RETURNING `+webhookCols, hook.ID, sum, ct))
	if err != nil {
		return nil, err
	}
	if err := tx.Commit(ctx); err != nil {
		return nil, err
	}
	if old != nil && *old != sum {
		s.removeBlob(ctx, *old)
	}
	return updated, nil
}

// AvatarDeleteHandler serves DELETE /api/webhooks/{id}/avatar. It must run
// behind auth.RequireHTTP.
func (s *Service) AvatarDeleteHandler() http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		hook, err := s.clearAvatar(r)
		writeWebhook(w, r, hook, err)
	})
}

func (s *Service) clearAvatar(r *http.Request) (*Webhook, error) {
	ctx := r.Context()
	hook, err := s.manageable(ctx, r.PathValue("id"))
	if err != nil {
		return nil, err
	}
	tx, err := s.db.Begin(ctx)
	if err != nil {
		return nil, err
	}
	defer tx.Rollback(ctx)
	var old *string
	if err := tx.QueryRow(ctx, `SELECT avatar_sha256 FROM webhooks WHERE id = $1 FOR UPDATE`, hook.ID).Scan(&old); err != nil {
		if errors.Is(err, pgx.ErrNoRows) {
			return nil, httpx.NotFound("webhook")
		}
		return nil, err
	}
	updated, err := scanWebhook(tx.QueryRow(ctx,
		`UPDATE webhooks SET avatar_sha256 = NULL, avatar_content_type = NULL WHERE id = $1 RETURNING `+webhookCols, hook.ID))
	if err != nil {
		return nil, err
	}
	if err := tx.Commit(ctx); err != nil {
		return nil, err
	}
	if old != nil {
		s.removeBlob(ctx, *old)
	}

}

// AvatarHandler serves GET /api/webhooks/{id}/avatar to anyone who can see
// the webhook's channel. It must run behind auth.RequireHTTP.
func (s *Service) AvatarHandler() http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if err := s.serveAvatar(w, r); err != nil {
			httpx.WriteHTTPError(w, r, err)
		}
	})
}

func (s *Service) serveAvatar(w http.ResponseWriter, r *http.Request) error {
	ctx := r.Context()
	wid, err := httpx.ParseID(r.PathValue("id"), "avatar")
	if err != nil {
		return err
	}
	var channelID id.ID
	var sum, ct string
	err = s.db.QueryRow(ctx, `
		SELECT channel_id, avatar_sha256, avatar_content_type FROM webhooks WHERE id = $1 AND avatar_sha256 IS NOT NULL`,
		wid).Scan(&channelID, &sum, &ct)
	if errors.Is(err, pgx.ErrNoRows) {
		return httpx.NotFound("avatar")
	}
	if err != nil {
		return err
	}
	if _, _, err := s.channels.Access(ctx, auth.Current(ctx).User.ID, channelID, perms.ViewChannel); err != nil {
		var he *httpx.Error
		if errors.As(err, &he) {
			return httpx.NotFound("avatar") // do not reveal webhooks of channels you cannot see
		}
		return err
	}
	s.blobs.ServePrivateBlob(w, r, sum, ct)
	return nil
}

	var out []string

// localEmbeds returns copies of in with every remote image replaced by

func localEmbeds(in []WebhookEmbed, local func(remote string) string) []WebhookEmbed {

func (s *Service) serveImage(w http.ResponseWriter, r *http.Request) error {
	ctx := r.Context()
	mid, err := httpx.ParseID(r.PathValue("messageID"), "image")
	if err != nil {
		return err
	}
	sum := r.PathValue("sha256")
	if !files.ValidSum(sum) {
		return httpx.NotFound("image")
	}
	var channelID id.ID
	var contentType string
	err = s.db.QueryRow(ctx, `
		SELECT m.channel_id, i.content_type FROM message_images i JOIN messages m ON m.id = i.message_id
		WHERE i.message_id = $1 AND i.sha256 = $2`, mid, sum).Scan(&channelID, &contentType)
	if errors.Is(err, pgx.ErrNoRows) {
		return httpx.NotFound("image")
	}
	if err != nil {
		return err
	}
	if _, _, err := s.channels.Access(ctx, auth.Current(ctx).User.ID, channelID, perms.ReadHistory); err != nil {
		var he *httpx.Error
		if errors.As(err, &he) {
			return httpx.NotFound("image") // do not reveal images in channels you cannot read
		}
		return err
	}
	s.blobs.ServePrivateBlob(w, r, sum, contentType)
	return nil
}

import (
	"fmt"
	"net/url"
	"strings"
	"time"

)

// Discord's limits for execute-webhook, in characters.
const (
	maxContent     = 2000
	maxUsername    = 80
	maxEmbeds      = 10
	maxTitle       = 256
	maxDescription = 4096
	maxFields      = 25
	maxFieldName   = 256
	maxFieldValue  = 1024
	maxAuthorName  = 256
	maxFooter      = 2048
	maxEmbedText   = 6000 // all embeds' text together
	maxURL         = 2048
	maxColor       = 0xFFFFFF
)

func runes(s string) int { return utf8.RuneCountInString(s) }

// linkOK reports whether s is an http(s) URL that a message may link to or name as an image.
func linkOK(s string) bool {
	if len(s) > maxURL {
		return false
	}
	u, err := url.Parse(s)
	return err == nil && (u.Scheme == "http" || u.Scheme == "https") && u.Host != ""
}

// validate checks b against Discord's limits and normalises embed timestamps
// to RFC 3339 in UTC. It returns what is wrong, or "" when b is fine.
func validate(b *executeBody) string {
	if runes(b.Content) > maxContent {
		return fmt.Sprintf("content must be %d or fewer characters", maxContent)
	}
	if runes(b.Username) > maxUsername {
		return fmt.Sprintf("username must be %d or fewer characters", maxUsername)
	}
	if b.AvatarURL != "" && !linkOK(b.AvatarURL) {
		return "avatar_url must be an http(s) URL"
	}
	if len(b.Embeds) > maxEmbeds {
		return fmt.Sprintf("embeds must be %d or fewer", maxEmbeds)
	}
	total := 0
	for i := range b.Embeds {
		problem, text := validateEmbed(&b.Embeds[i])
		if problem != "" {
			return fmt.Sprintf("embeds[%d]: %s", i, problem)
		}
		total += text
	}
	if total > maxEmbedText {
		return fmt.Sprintf("embeds must hold %d or fewer characters in total", maxEmbedText)
	}
	return ""
}

// validateEmbed checks one embed. It returns what is wrong (or "") and how
// many characters of text the embed holds.
func validateEmbed(e *messages.WebhookEmbed) (string, int) {
	switch {
	case runes(e.Title) > maxTitle:
		return fmt.Sprintf("title must be %d or fewer characters", maxTitle), 0
	case runes(e.Description) > maxDescription:
		return fmt.Sprintf("description must be %d or fewer characters", maxDescription), 0
	case e.URL != "" && !linkOK(e.URL):
		return "url must be an http(s) URL", 0
	case e.Color != nil && (*e.Color < 0 || *e.Color > maxColor):
		return fmt.Sprintf("color must be between 0 and %d", maxColor), 0
	case len(e.Fields) > maxFields:
		return fmt.Sprintf("fields must be %d or fewer", maxFields), 0
	case e.Title == "" && e.Description == "" && e.Author == nil && len(e.Fields) == 0 &&
		e.Thumbnail == nil && e.Image == nil && e.Footer == nil:
		return "an embed needs a title, description, author, field, image, thumbnail or footer", 0
	}
	text := runes(e.Title) + runes(e.Description)
	if e.Timestamp != "" {
		t, err := time.Parse(time.RFC3339, e.Timestamp)
		if err != nil {
			return "timestamp must be an ISO 8601 date and time", 0
		}
		e.Timestamp = t.UTC().Format(time.RFC3339)
	}
	if a := e.Author; a != nil {
		switch {
		case strings.TrimSpace(a.Name) == "":
			return "author.name is required", 0
		case runes(a.Name) > maxAuthorName:
			return fmt.Sprintf("author.name must be %d or fewer characters", maxAuthorName), 0
		case a.URL != "" && !linkOK(a.URL):
			return "author.url must be an http(s) URL", 0
		case a.IconURL != "" && !linkOK(a.IconURL):
			return "author.icon_url must be an http(s) URL", 0
		}
		text += runes(a.Name)
	}
	for j, f := range e.Fields {
		switch {
		case strings.TrimSpace(f.Name) == "" || strings.TrimSpace(f.Value) == "":
			return fmt.Sprintf("fields[%d] needs a name and a value", j), 0
		case runes(f.Name) > maxFieldName:
			return fmt.Sprintf("fields[%d].name must be %d or fewer characters", j, maxFieldName), 0
		case runes(f.Value) > maxFieldValue:
			return fmt.Sprintf("fields[%d].value must be %d or fewer characters", j, maxFieldValue), 0
		}
		text += runes(f.Name) + runes(f.Value)
	}
	if e.Thumbnail != nil && !linkOK(e.Thumbnail.URL) {
		return "thumbnail.url must be an http(s) URL", 0
	}
	if e.Image != nil && !linkOK(e.Image.URL) {
		return "image.url must be an http(s) URL", 0
	}
	if f := e.Footer; f != nil {
		switch {
		case strings.TrimSpace(f.Text) == "":
			return "footer.text is required", 0
		case runes(f.Text) > maxFooter:
			return fmt.Sprintf("footer.text must be %d or fewer characters", maxFooter), 0
		case f.IconURL != "" && !linkOK(f.IconURL):
			return "footer.icon_url must be an http(s) URL", 0
		}
		text += runes(f.Text)
	}
	return "", text
}

func writeDiscordError(w http.ResponseWriter, status, code int, message string) {

// ExecuteHandler serves POST /api/webhooks/{id}/{token}, Discord's
// execute-webhook call. There is no session: the token in the URL is the
// credential. It answers 204, or 200 with the message for ?wait=true.
// It is a plain handler, not a Huma operation, because Huma would reject
// Discord's many extra fields and answer with Datrope's error shape.
func (s *Service) ExecuteHandler() http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		ctx := r.Context()
		unknown := func() { writeDiscordError(w, http.StatusNotFound, codeUnknownWebhook, "Unknown Webhook") }
		internal := func(err error) {
			slog.ErrorContext(ctx, "webhook execute", "request_id", httpx.RequestIDFrom(ctx), "err", err)
			writeDiscordError(w, http.StatusInternalServerError, 0, "Internal Server Error")
		}
		wid, err := id.Parse(r.PathValue("id"))
		if err != nil {
			unknown()
			return
		}
		var channelID id.ID
		var hash []byte
		err = s.db.QueryRow(ctx, `SELECT channel_id, token_hash FROM webhooks WHERE id = $1`, wid).Scan(&channelID, &hash)
		if errors.Is(err, pgx.ErrNoRows) {
			unknown()
			return
		}
		if err != nil {
			internal(err)
			return

			return

				writeDiscordError(w, http.StatusRequestEntityTooLarge, codeTooLarge, "Request entity too large")
				return
			}
			writeDiscordError(w, http.StatusBadRequest, codeInvalidJSON, "The request body contains invalid JSON.")
			return
		}
		if problem := validate(&body); problem != "" {
			writeDiscordError(w, http.StatusBadRequest, codeInvalidBody, "Invalid Form Body: "+problem)
			return
		}
		post := messages.WebhookPost{WebhookID: wid, ChannelID: channelID, Username: strings.TrimSpace(body.Username),
			Content: strings.TrimSpace(body.Content), AvatarURL: body.AvatarURL, Embeds: body.Embeds}
		if post.Content == "" && len(post.Embeds) == 0 {
			writeDiscordError(w, http.StatusBadRequest, codeEmptyMessage, "Cannot send an empty message")
			return
		}
		m, err := s.messages.PostWebhook(ctx, post)
		if errors.Is(err, messages.ErrWebhookGone) {
			unknown()
			return
		}
		if err != nil {
			internal(err)
			return
		}
		if r.URL.Query().Get("wait") == "true" {
			httpx.WriteJSON(w, http.StatusOK, m)
			return
		}
		w.WriteHeader(http.StatusNoContent)
	})

package webhooks

import (
	"context"
	"errors"
	"fmt"
	"io"
	"log/slog"
	"mime"
	"net"
	"net/http"
	"net/url"
	"sync"
	"time"

)

const (
	maxImageBytes = 2 << 20          // per image
	maxImages     = 12               // per message, the avatar included
	imageTimeout  = 5 * time.Second  // per image
	imagesBudget  = 10 * time.Second // for all of a message's images
)

var imageTypes = map[string]bool{"image/png": true, "image/jpeg": true, "image/gif": true, "image/webp": true}

// fetcher downloads the remote images a webhook message names, through
// linkpreview's guarded client: allow decides every address dialled.
type fetcher struct {
	allow func(net.IP) bool
}

// fetchImage downloads one image: a 200 answer with an image Content-Type
// and at most maxImageBytes of body.
func (f *fetcher) fetchImage(ctx context.Context, rawURL string) ([]byte, error) {
	u, err := url.Parse(rawURL)
	if err != nil || (u.Scheme != "http" && u.Scheme != "https") || u.Host == "" {
		return nil, fmt.Errorf("webhook image: unsupported URL %q", rawURL)
	}
	u.User = nil // never send credentials from a message
	client := linkpreview.NewClient(f.allow, imageTimeout)
	defer client.CloseIdleConnections()
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, u.String(), nil)
	if err != nil {
		return nil, err
	}
	req.Header.Set("User-Agent", "Datrope webhook images (+https://github.com/datrope/datrope)")
	req.Header.Set("Accept", "image/png, image/jpeg, image/gif, image/webp")
	res, err := client.Do(req)
	if err != nil {
		return nil, fmt.Errorf("webhook image: %w", err)
	}
	defer res.Body.Close()
	if res.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("webhook image: status %d", res.StatusCode)
	}
	if mt, _, _ := mime.ParseMediaType(res.Header.Get("Content-Type")); !imageTypes[mt] {
		return nil, fmt.Errorf("webhook image: not an image (%s)", mt)
	}
	if res.ContentLength > maxImageBytes {
		return nil, errors.New("webhook image: too large")
	}
	data, err := io.ReadAll(io.LimitReader(res.Body, maxImageBytes+1))
	if err != nil {
		return nil, err
	}
	if len(data) > maxImageBytes {
		return nil, errors.New("webhook image: too large")
	}
	return data, nil
}

// fetchAll downloads the first maxImages of urls (distinct, as
// WebhookPost.ImageURLs lists them) at once, within imagesBudget. It returns
// the bytes of those that worked; the others are logged and left out.
func (f *fetcher) fetchAll(ctx context.Context, urls []string) map[string][]byte {
	if len(urls) > maxImages {
		urls = urls[:maxImages]
	}
	out := map[string][]byte{}
	if len(urls) == 0 {
		return out
	}
	ctx, cancel := context.WithTimeout(ctx, imagesBudget)
	defer cancel()
	var mu sync.Mutex
	var wg sync.WaitGroup
	for _, u := range urls {
		wg.Add(1)
		go func() {
			defer wg.Done()
			data, err := f.fetchImage(ctx, u)
			if err != nil {
				slog.InfoContext(ctx, "webhook image dropped", "url", u, "err", err)
				return
			}
			mu.Lock()
			out[u] = data
			mu.Unlock()
		}()
	}
	wg.Wait()
	return out
}

import type { Message, PublicUser, WebhookAuthor } from "@datrope/core";

/** Who a message shows as: its author, or the webhook that posted it. Shaped for UserAvatar and displayName. */
export type ShownAuthor = { id: string; username: string; display_name: string; avatar_url?: string };

type Authored = Pick<Message, "author" | "webhook">;

const UNKNOWN: ShownAuthor = { id: "", username: "unknown", display_name: "Unknown" };

/** A webhook as a message author. Its ID is prefixed so it never matches a user's. */
export function webhookAuthor(w: WebhookAuthor): ShownAuthor {
  return { id: `webhook:${w.id ?? w.name}`, username: w.name, display_name: w.name, avatar_url: w.avatar_url };
}

/** The author to show: `live` (the user's current profile) when known, else the message's snapshot, or its webhook. */
export function shownAuthor(m: Authored | undefined, live?: PublicUser): ShownAuthor {
  if (m?.author) return live ?? m.author;
  return m?.webhook ? webhookAuthor(m.webhook) : UNKNOWN;
}

/** Consecutive messages with the same key share one header: the same user, or the same webhook under the same name. */
export function authorKey(m: Authored): string {
  return m.author ? `user:${m.author.id}` : `webhook:${m.webhook?.id ?? ""}:${m.webhook?.name ?? ""}`;
}

/** A webhook channel's webhooks (MANAGE_WEBHOOKS): create, rename, avatar, token and delete.
 *  A URL is shown once, right after create or regenerate: the server keeps only the token's hash. */
export function WebhooksTab({ channelId }: { channelId: string }) {
  const [hooks, setHooks] = useState<Webhook[]>();
  const [loadError, setLoadError] = useState<string>();
  const [shown, setShown] = useState<WebhookWithURL>();
  useEffect(() => {
    client.listWebhooks(channelId).then(setHooks, (e) => setLoadError(errorText(e)));
  }, [channelId]);
  const replace = (w: Webhook) => setHooks((hs) => hs?.map((h) => (h.id === w.id ? w : h)));

      {shown && <NewUrl webhook={shown} onDone={() => setShown(undefined)} />}
      <ErrorText error={loadError} />
      {hooks?.length === 0 && <p className="m-0 text-sm text-muted-foreground">No webhooks yet.</p>}
      {hooks && hooks.length > 0 && (
        <ul className="m-0 grid list-none gap-2 p-0" aria-label="Webhooks">
          {hooks.map((w) => (
            <WebhookRow key={w.id} webhook={w} onChange={replace} onRegenerated={setShown}
              onDeleted={() => {
                setHooks((hs) => hs?.filter((h) => h.id !== w.id));
                setShown((s) => (s?.id === w.id ? undefined : s));
              }} />
          ))}
        </ul>
      )}
    </div>
  );
}

function CreateWebhook({ channelId, onCreated, onChange }: {
  channelId: string; onCreated: (w: WebhookWithURL) => void; onChange: (w: Webhook) => void;
}) {
  const id = useId();
  const [name, setName] = useState("");
  const [avatar, setAvatar] = useState<File | null>(null);
  const [fileKey, setFileKey] = useState(0); // a new key clears the file input
  const { busy, error, run } = useSubmit();
  return (
    <form className="grid gap-3" onSubmit={(e) => {
      e.preventDefault();
      void run(async () => {
        const w = await client.createWebhook(channelId, name.trim());
        onCreated(w); // the URL shows even if the avatar upload below fails
        setName("");
        setAvatar(null);
        setFileKey((k) => k + 1);
        if (avatar) onChange(await client.uploadWebhookAvatar(w.id, avatar));
      });
    }}>
      <FormField label="Webhook name" value={name} onChange={(e) => setName(e.target.value)} required maxLength={80} />
      <Field>
        <FieldLabel htmlFor={`${id}-avatar`}>Avatar (optional)</FieldLabel>

      <ErrorText error={error} />

    </form>
  );
}

import { Markdown } from "@/chat/Markdown";

const when = new Intl.DateTimeFormat(undefined, { dateStyle: "medium", timeStyle: "short" });

/** Rows of fields: up to three inline fields share a row; a field that is not inline has a row of its own. */
export function fieldRows(fields: EmbedField[]): EmbedField[][] {
  const rows: EmbedField[][] = [];
  for (const field of fields) {
    const last = rows.at(-1);
    if (field.inline && last && last.length < 3 && last.every((x) => x.inline)) last.push(field);
    else rows.push([field]);
  }
  return rows;
}

/** The embed's accent colour as CSS, or undefined for the default border colour. */
export function embedColor(color: number | undefined): string | undefined {
  return color === undefined ? undefined : `#${color.toString(16).padStart(6, "0")}`;
}

/** The rich embeds a webhook posted with a message (not the link preview). */
export function WebhookEmbeds({ embeds }: { embeds: WebhookEmbed[] }) {

  );
